## 1. 项目概述

### 1.1 建设目标

建设一套覆盖 **“客户、设计、报价、订单、设备、工厂、仓储、采购、财务、审批、数据”** 的一体化管理系统，实现：

1. **客户与销售在线**：客户来源、归属业务员、设计图案、按布料长度报价、订单跟进全程可查。
2. **多工厂协同**：客户设备分布在不同工厂，由公司专职设备操作员操作；每个工厂有独立仓储，支持跨工厂调货。
3. **订单生产闭环**：客户提供图案 → 业务员按长度报价 → 订单审批 → 排产到工厂/客户设备 → 领料生产 → 质检/返工 → 入库发货 → 对账收款。
4. **业财记录闭环**：客户收付款、对账、原材料采购、供应商付款在同一系统内记录，不依赖第三方财务系统。
5. **权限精细可控**：按部门、工厂、岗位、业务员、角色、字段和数据范围后台手动配置。
6. **管理可视化**：总部看全局，工厂看本厂，业务员看自己的客户和订单。
7. **公网可访问**：通过域名和浏览器访问，所有工厂均可登录，无需安装客户端或小程序。

### 1.2 本次确认的 10 项业务规则及系统落地

| # | 已确认规则 | 系统落地方式 |
|---|---|---|
| 1 | 客户设备放在公司不同地方的工厂里，每个工厂都有仓储；不同工厂可以调货；由公司专门的设备操作员操作；不收费 | 增加“工厂”主数据；设备归属工厂/车间；仓库归属工厂；支持跨工厂调拨；设备绑定公司操作员；设备使用费不纳入收费与成本 |
| 2 | 客户自己设计图案，业务员根据布料长度报价；原材料由公司提供 | 增加客户图案库、报价单；订单按米/码计价；原材料由公司采购，不做客供料 |
| 3 | 财务不涉及第三方对接，主要负责客户收付款记录、对账、原材料采购等 | 财务做内部往来、采购、付款、资金流水、对账；不做银行直连、电子发票接口、总账凭证接口 |
| 4 | 员工考勤功能去掉 | 删除打卡、排班、请假、加班、出差、补卡、考勤统计；员工模块保留组织、档案、账号、操作员管理 |
| 5 | 审批层级按公司组织架构层级逐层审批；审批金额可以手动设置 | 默认按直属上级逐级向上审批；后台按业务类型/金额区间配置终审层级和金额阈值 |
| 6 | 客户来源记录，销售归属业务员 | 客户来源必填；客户必须归属具体业务员；数据权限按业务员/销售团队控制 |
| 7 | 订单变更需要业务员确认；质量返工由业务员确认；产生相应记录 | 增加订单变更单、返工确认单；业务员确认是必经节点；记录确认时间、意见、客户沟通和影响 |
| 8 | 外网域名部署上线，所有工厂都可以登录访问 | 公网域名 + HTTPS + 浏览器访问；按工厂/部门/角色做数据隔离；做好公网安全防护和备份 |
| 9 | 不需要小程序，有后台和页面就行 | 只建设 PC Web 管理后台和业务操作页面；不做小程序、独立 App、PDA 专用客户端 |
| 10 | 没有旧系统数据 | 不做旧系统数据迁移；上线前录入组织、工厂、客户、设备、物料、期初库存/往来等基础数据 |

### 1.3 核心业务主线

```text
客户建档（来源、归属业务员）
   ↓
客户提供设计图案 → 图案建档/版本管理
   ↓
业务员按布料长度报价（元/米或元/码）→ 报价审批/客户确认
   ↓
订单（归属客户、业务员、生产工厂）
   ↓
订单审批（组织层级逐级 + 金额阈值）
   ↓
排产（工厂 + 该客户的设备 + 公司操作员）
   ↓
领料（公司原材料）→ 生产 → 按长度报工 → 质检
   ↓
不合格返工（业务员确认）或成品入库
   ↓
发货/客户签收
   ↓
客户对账 → 收款记录 → 订单关闭
```

支撑链路：

```text
原材料采购：采购申请 → 采购订单 → 到货入库 → 应付 → 付款
跨厂调货：工厂 A 仓库 → 调拨单 → 在途 → 工厂 B 仓库接收
设备管理：客户设备进场 → 安装验收 → 分配操作员 → 运行/维保/维修
审批：所有金额、变更、返工、采购、付款、调拨按组织层级逐级审批
```

### 1.4 系统边界

**本期包含：**

- 员工与组织（不含考勤）、权限管理、客户与图案/报价、设备管理、订单与生产、财务与采购、审批、仓储、首页大屏。
- 多工厂、多仓库、跨工厂调拨、设备操作员、按布料长度计价。
- 通用能力：编码规则、数据字典、附件、消息/待办、导入导出、打印、操作日志、报表。
- 公网域名部署，PC 浏览器访问。

**本期不包含：**

- 员工考勤、排班、打卡、请假、加班、出差、补卡、薪资核算。
- 小程序、独立 App、PDA 专用客户端；如需扫码，可使用浏览器+扫码枪。
- 第三方财务软件、银行直连、电子发票、税控、总账、税务申报接口。
- 客户设备使用费/托管费（已确认不收费）。
- 客户提供原材料（客供料）模式；本期原材料由公司采购。
- 设备 IoT 自动采集、复杂 APS 高级排程（可作为后续扩展）。
- 旧系统数据迁移。

### 1.5 设计原则

1. **主数据统一**：客户、工厂、物料、设备、仓库、员工、供应商一处维护、全系统引用。
2. **单据驱动**：订单、生产、库存、收付款必须有单据，禁止直接改数。
3. **工厂隔离**：默认按工厂隔离数据，总部/管理层按授权跨厂查看。
4. **逐级审批**：审批链默认沿组织架构逐层向上，金额阈值后台可调。
5. **业务员负责制**：客户和销售归属业务员，订单变更、返工必须业务员确认。
6. **权限最小化**：敏感价格、成本、客户资料、设计文件按角色和字段授权。
7. **操作留痕**：变更、返工、调拨、收付款、权限调整全部可追溯。
8. **Web 优先**：PC 浏览器访问，不依赖特定客户端。

## 2. 总体架构与核心业务模型

### 2.1 功能架构

```text
┌──────────────────────────────────────────────────────────────┐
│ 访问层：公网域名 + HTTPS + PC 浏览器（总部/各工厂）              │
├──────────────────────────────────────────────────────────────┤
│ 业务层：员工组织｜权限｜客户/图案/报价｜设备｜订单｜财务采购｜审批｜仓储｜大屏 │
├──────────────────────────────────────────────────────────────┤
│ 平台层：组织/工厂｜用户角色｜工作流｜消息待办｜附件｜编码｜报表｜日志    │
├──────────────────────────────────────────────────────────────┤
│ 数据层：主数据｜订单/生产｜设备｜库存｜采购/财务｜审批｜分析指标        │
└──────────────────────────────────────────────────────────────┘
```

### 2.2 组织与工厂模型

```text
公司
 ├─ 工厂 A（生产地点）
 │   ├─ 车间/产线
 │   ├─ 部门（生产、设备、仓储、业务等）
 │   ├─ 仓库（原料仓、成品仓、辅料仓等）
 │   └─ 客户设备
 ├─ 工厂 B
 │   ├─ 车间/产线
 │   ├─ 部门
 │   ├─ 仓库
 │   └─ 客户设备
 └─ 总部职能部门（销售、财务、采购、人事、系统管理）
```

**规则：**

- 工厂是独立的生产地点，设备、仓库、操作员、生产工单都必须归属工厂。
- 客户归属业务员，不直接归属工厂；订单可选择生产工厂，生产工厂必须有该客户的设备或可调配资源。
- 每个工厂至少有一个仓库；仓库可分原料仓、成品仓、辅料仓、待检仓等。
- 工厂之间可调拨物料/成品，调拨需要审批、出库、在途、接收确认。
- 用户可归属一个主工厂，总部用户可跨厂；数据权限按工厂 + 部门 + 业务员控制。
- 工厂负责人可查看本厂订单、设备、库存、生产、人员；销售负责人可查看团队客户和订单。

### 2.3 核心实体关系

| 实体 | 关系 | 说明 |
|---|---|---|
| 客户 | 1:N 联系人、图案、报价、订单、设备、应收、对账 | 客户必须归属业务员，来源必填 |
| 图案 | N:1 客户；1:N 报价/订单 | 客户设计的图案，版本化管理 |
| 报价 | N:1 客户/图案；1:N 订单 | 按布料长度报价，可转订单 |
| 订单 | 1:N 订单行、工单、发货单、应收 | 订单归属客户、业务员、生产工厂 |
| 订单行 | 1:N 工单 | 按图案/布料/颜色/工艺拆分 |
| 工单 | N:1 工厂、客户设备、操作员 | 使用该客户设备生产 |
| 设备 | N:1 客户、工厂 | 客户所有，公司工厂使用，不收使用费 |
| 仓库 | N:1 工厂；1:N 库位、库存 | 每厂独立仓储，可跨厂调拨 |
| 库存 | N:1 物料、仓库、批次/卷 | 原材料、成品、辅料分开管理 |
| 采购 | 1:N 采购行、入库、应付 | 原材料由公司采购 |
| 应收/应付 | N:1 客户/供应商；1:N 收付款/对账 | 内部财务记录，不对接第三方 |
| 员工 | N:1 工厂/部门/岗位；1:N 账号、操作员资格 | 不含考勤 |
| 审批实例 | 1:1 业务单据 | 按组织层级逐级审批 |

## 3. 员工与组织（不含考勤）

### 3.1 组织架构

- 公司 → 工厂 → 部门 → 岗位的多级组织树。
- 部门信息：名称、编码、所属工厂、上级部门、负责人、编制、状态、生效日期。
- 岗位信息：岗位名称、职级、所属部门、岗位职责、默认角色。
- 汇报关系：行政上级、业务上级；审批链默认按行政上级逐级向上。
- 支持员工主部门 + 兼岗；数据权限以主部门/主工厂为主，兼岗按授权扩展。
- 组织调整保留历史任职记录，不影响历史订单、审批和操作记录。

**规则：**

- 部门下有在职员工或未结业务时不能删除，只能停用。
- 工厂撤并/部门调整需有生效日期，审批链按单据提交时的组织快照计算。
- 部门负责人变更后，新发起单据使用新负责人；历史单据保留原审批人。

### 3.2 工厂管理

| 字段 | 说明 |
|---|---|
| 工厂编码/名称 | 唯一编码，展示名称 |
| 地址/联系人 | 工厂地址、负责人、联系电话 |
| 状态 | 启用、停用、筹建 |
| 下属仓库 | 该工厂的原料仓、成品仓、辅料仓等 |
| 下属设备 | 客户设备清单及位置 |
| 人员 | 厂长、生产、设备、仓储、业务等 |
| 数据权限 | 本厂用户默认只看本厂；总部角色可跨厂 |

**规则：**

- 设备、仓库、工单必须归属工厂，不能跨工厂悬空。
- 跨厂调拨由调出工厂发起、调入工厂接收，双方都有记录。
- 工厂停用前检查未完成订单、库存、设备和人员。
- 工厂之间不共享库存数量，调拨必须走单据。

### 3.3 员工档案

| 分类 | 字段示例 | 权限 |
|---|---|---|
| 基本信息 | 工号、姓名、性别、手机、邮箱、照片、紧急联系人 | 人事可编辑，其他人按通讯录范围 |
| 任职信息 | 工厂、部门、岗位、职级、入职日期、直属上级、员工类型 | 人事/部门负责人 |
| 合同信息 | 合同编号、类型、起止日期、附件、到期提醒 | 人事 |
| 资质信息 | 设备操作证、培训记录、有效期 | 人事/设备主管 |
| 敏感信息 | 身份证、银行卡、薪资等 | 加密/脱敏，单独授权 |
| 账号信息 | 系统账号、角色、状态、最后登录 | 系统管理员 |

**说明：**

- 本期不记录打卡、排班、请假、加班、出差、补卡、考勤统计。
- 员工档案用于组织归属、审批链、订单业务员、设备操作员、权限分配。
- 身份证、银行卡等敏感信息如无业务需要，建议不采集或仅保留必要字段。

### 3.4 账号与角色

- 一名员工一个账号，账号与员工档案绑定。
- 账号状态：启用、停用、锁定；离职/长期离岗及时停用。
- 角色按岗位/部门分配，支持用户额外授权和显式禁止。
- 支持管理员重置密码、强制下线、登录日志查询。
- 使用系统账号密码登录，不依赖外部平台或小程序。

### 3.5 设备操作员管理

- 设备操作员是员工的一种业务身份，可绑定一台或多台设备。
- 记录操作员所属工厂、可操作设备类型、操作证/培训有效期。
- 排产/工单指派操作员时校验：是否本厂、是否具备该设备操作资格、是否已被占用。
- 工单报工记录操作员，便于追溯质量和产量。
- 操作员工作量按工单/产量统计，不做考勤统计。
- 操作证到期提醒，过期后限制排产/报工（可配置）。

### 3.6 员工生命周期

1. **入职**：录入档案 → 分配工厂/部门/岗位 → 开通账号 → 分配角色 → 如为操作员则登记资质。
2. **调岗/调厂**：审批 → 更新任职 → 权限按新工厂/部门调整 → 客户/设备/订单交接（如涉及）。
3. **离职**：审批 → 交接客户、订单、设备、资料、借款 → 停用账号 → 回收权限 → 保留历史记录。
4. **返聘**：可关联原档案，避免历史订单/审批记录混淆。

**提醒：**

- 合同到期、操作证到期、试用期到期。
- 长期未登录账号、离职未交接、权限异常。

### 3.7 员工报表与验收

**报表：**

- 工厂/部门在职人数、岗位分布、合同到期清单。
- 设备操作员清单、资质到期、可操作设备。
- 员工账号状态、角色分配、长期未登录。
- 业务员客户/订单归属统计（与客户、订单模块联动）。

**验收要点：**

- 组织树、工厂、部门、岗位可维护，历史任职可追溯。
- 员工调岗/调厂后权限和审批链正确变化。
- 操作员资质校验能阻止无证排产/报工。
- 不出现任何考勤相关菜单、字段和报表。
- 离职账号及时停用，权限回收有记录。

## 4. 权限管理（部门/工厂可后台手动配置）

### 4.1 权限模型

采用 **RBAC + 组织/工厂数据权限 + 字段权限 + 操作权限 + 审批权限**：

```text
用户最终权限 =
  部门/工厂默认权限模板
  ∪ 岗位/角色权限
  ∪ 用户额外授权
  − 显式禁止
  并受“部门/工厂数据权限上限”约束
```

- **功能权限**取并集，显式禁止优先。
- **数据权限**取并集，但不得超过部门/工厂允许的最大范围。
- **字段权限**：可见、可编辑、脱敏、不可见。
- **审批权限**与业务操作权限分离。
- **职责分离**：系统管理员配置权限，不默认拥有业务数据。

### 4.2 权限对象

| 对象 | 说明 |
|---|---|
| 用户 | 员工账号，支持启用/停用/锁定 |
| 角色 | 权限集合，如销售、业务主管、厂长、生产主管、设备管理员、仓管、采购、财务、人事 |
| 部门 | 权限继承和分配的基本单位 |
| 工厂 | 数据隔离维度，决定可见的订单、设备、库存、人员 |
| 岗位 | 绑定默认角色，调岗自动调整 |
| 菜单/页面 | 模块和页面访问 |
| 操作/按钮 | 新增、编辑、审批、导出、作废、红冲等 |
| API | 后端接口级校验，防止绕过页面 |
| 数据资源 | 客户、图案、报价、订单、设备、库存、采购、财务单据 |
| 字段 | 价格、成本、毛利、折扣、供应商报价、客户联系方式、设计文件 |

**权限编码示例：**

```text
customer:customer:view
customer:design:download
quotation:quote:create
order:order:approve
order:order:change_confirm
production:rework:confirm
equipment:equipment:transfer
warehouse:transfer:approve
purchase:purchase_order:create
finance:receipt:create
system:permission:grant
```

### 4.3 数据权限范围

| 范围 | 说明 | 典型场景 |
|---|---|---|
| 全部数据 | 全公司、全部工厂 | 总经理、财务负责人 |
| 本工厂 | 仅所属工厂 | 厂长、工厂仓管、工厂生产主管 |
| 本工厂及指定工厂 | 手动勾选协作工厂 | 跨厂调拨、总部生产 |
| 本部门及下级 | 组织树向下 | 销售经理、部门负责人 |
| 本部门 | 仅本部门 | 部门主管 |
| 仅本人客户/订单 | 业务员归属 | 销售业务员 |
| 本人及下属 | 汇报关系向下 | 销售主管 |
| 自定义 | 指定人员/客户/工厂/仓库 | 专项小组 |
| 无权限 | 不可见 | 默认 |

**典型配置：**

- 业务员：只看自己归属的客户、图案、报价、订单；可看自己订单的生产进度和收款记录。
- 销售主管：看本部门/团队业务员的数据；可审批报价折扣和订单变更。
- 厂长：看本厂订单、工单、设备、库存、人员；不看客户成本和其他工厂财务。
- 生产主管：看本厂工单、设备、物料库存；不看订单价格和客户回款。
- 设备管理员：看本厂客户设备、操作员、维保记录；可跨厂查看设备台账（按授权）。
- 仓管：看指定工厂/仓库的库存和出入库；可看数量，库存金额按授权。
- 采购：看供应商、采购订单、到货；付款信息按授权。
- 财务：看全部或指定工厂的应收、应付、收付款、对账；可看订单金额，成本字段单独授权。
- 人事：看员工档案、组织、合同、操作员资质；不看业务订单。
- 系统管理员：系统配置和权限，不默认进入业务数据。
- 总经理：全公司经营数据、关键审批、大屏。

### 4.4 部门/工厂权限后台配置流程

**入口：权限中心 → 部门/工厂权限配置**

1. 选择工厂或部门，查看组织树、负责人、人数、当前模板。
2. 选择权限模板（销售部、生产部、设备部、仓储部、采购部、财务部、人事部、工厂管理层、总部管理层）。
3. 配置菜单和操作按钮（查看、新增、编辑、审批、导出、作废）。
4. 配置数据范围（本厂/本部门/本人客户/全部/指定工厂）。
5. 配置字段权限（价格、成本、毛利、折扣、供应商报价、客户手机号、设计文件下载）。
6. 配置岗位差异（业务员 vs 销售主管、仓管 vs 仓库主管）。
7. 配置用户例外（临时增权/禁权，填写原因和有效期）。
8. 预览某个用户的最终菜单、数据范围、字段可见性。
9. 提交审批（部门/工厂负责人 + 系统管理员，可配置）。
10. 生效并记录变更前后差异，支持按时间回滚。

**规则：**

- 子部门默认继承上级模板，可覆盖；上级可锁定关键权限，禁止下级扩大。
- 工厂用户默认只能看本厂；跨厂权限必须单独授权。
- 业务员离职/调岗，客户必须交接，权限自动回收。
- 跨部门/跨厂协作通过项目/订单团队成员授权，设置只读/可编辑和有效期。
- 权限变更不影响历史审批责任。
- 权限缓存要及时刷新，避免改了不生效。

### 4.5 字段级与敏感数据权限

| 数据 | 默认可见 | 限制 | 额外授权 |
|---|---|---|---|
| 客户联系方式 | 归属业务员、客服 | 手机号脱敏 | 导出需审批 |
| 报价/订单单价 | 业务员、销售主管、财务 | 成本、毛利默认隐藏 | 总经理/财务负责人 |
| 设计图案文件 | 归属业务员、设计、生产 | 下载水印、禁止外传 | 按客户/订单授权 |
| 供应商报价 | 采购、财务 | 业务员不可见 | 采购负责人 |
| 库存成本 | 财务、仓储主管 | 仓管员仅数量 | 按仓库授权 |
| 收付款/银行信息 | 财务 | 账号脱敏 | 出纳/会计 |
| 员工身份证/银行卡 | 人事、财务 | 脱敏 | 单独授权+日志 |

**敏感操作：**

- 批量导出客户、订单、设计文件、财务数据需二次确认并记录用途。
- 修改权限、作废单据、跨厂调拨、付款需填写原因。
- 管理员账号建议启用强密码/MFA；高权限账号限制登录 IP（可选）。

### 4.6 临时授权、代理与审计

- **临时授权**：项目/出差/紧急任务申请临时角色或数据权限，设置起止时间，到期自动回收。
- **审批代理**：员工请假/离岗时可指定代理人处理审批，仅转移审批待办，不转移数据权限，记录代理期限。
- **权限申请**：员工发起 → 部门/工厂负责人 → 系统管理员 → 生效，关联权限项和期限。
- **定期复核**：每季度/半年生成权限清单，部门/工厂负责人确认；长期未登录账号提醒/停用。
- **审计日志**：谁、何时、给谁、改了什么权限、原因、审批单号；支持按人/时间/操作人查询。
- **风险报告**：长期未用权限、离职未回收、越权尝试、付款审批与执行同一人、角色过多。

### 4.8 验收要点

## 5. 客户系统

### 5.1 客户主数据

| 分类 | 字段 |
|---|---|
| 基本信息 | 客户编码、客户名称、简称、客户类型、统一社会信用代码、行业、区域 |
| 来源与归属 | 客户来源（必填）、归属业务员（必填）、归属部门、协作人、首次合作日期 |
| 联系信息 | 联系人、职务、手机、邮箱、微信、主联系人标记、地址（收货/对账/开票） |
| 商务信息 | 结算方式、账期、信用额度（可选）、默认税率、币种、常用生产工厂 |
| 开票信息 | 开票抬头、税号、地址、电话、开户行、账号 |
| 附件 | 营业执照、合同、质量协议、客户设计确认单、现场照片 |
| 状态 | 潜在、合作中、暂停、流失、黑名单 |

**客户来源字典（可后台维护）：**

- 展会、老客户转介绍、业务员拜访、电话开发、线上咨询、行业协会、广告投放、其他。

**规则：**

- 客户来源和归属业务员为必填项，未填写不能保存。
- 客户归属业务员变更需审批并记录原因；离职时客户必须交接。
- 客户名称、信用额度、结算方式、开票信息变更需审批。
- 按名称、信用代码、手机号查重；合并客户需审批，保留旧编号映射。
- 客户可设置“常用生产工厂”，但订单仍可选择实际生产工厂。

### 5.2 客户归属与交接

- 客户默认归属一名业务员；销售主管可查看团队客户。
- 业务员离职/调岗时，客户、未结订单、报价、应收一并交接，交接清单审批。
- 客户长期无交易可标记“沉默/流失”，重新激活需业务员确认。
- 客户冻结：严重逾期或风险客户可暂停下单/发货，需特批解冻。
- 客户黑名单：需总经理审批后才能恢复合作。
- 本期不做复杂公海池规则；如需公海，可在后续版本增加“未跟进回收/认领”功能。

### 5.3 客户图案库（设计文件）

客户自己设计图案，系统需要管理图案文件及其版本，并保护客户知识产权。

**图案档案字段：**

- 图案编号、图案名称、所属客户、客户图案编号。
- 设计文件（AI/PDF/JPG/PSD 等）、预览图、文件大小、上传人、上传时间。
- 花型尺寸、循环/接回、颜色数量、配色方案、适用布料、工艺要求。
- 版本号、变更说明、客户确认状态、确认人/时间。
- 保密等级、可下载人员范围、水印设置。
- 关联报价、订单、生产工单。

**功能：**

- 上传/替换图案文件，保留历史版本；订单引用具体版本，避免生产错版。
- 在线预览（图片/PDF），下载需权限，可加水印和下载日志。
- 图案变更需客户确认/业务员确认，生成变更记录。
- 图案按客户隔离，其他客户和无关人员不可见。
- 图案可关联颜色/配色，同一图案多个配色分别管理。
- 支持按图案/客户/时间检索。

**规则：**

- 已被订单引用的图案版本不可删除，只能停用。
- 生产必须使用订单指定的图案版本；换版需走订单变更。
- 设计文件下载、外发、打印均记录日志。
- 客户图案仅用于该客户订单，不得用于其他客户（除非有书面授权）。

### 5.4 报价管理（按布料长度）

**报价流程：**

```text
客户提供图案/布料要求
 → 业务员选择图案、布料、门幅、工艺、颜色
 → 输入长度（米/码）和单价
 → 系统计算金额、损耗、最低收费
 → 报价审批（低于底价/折扣）
 → 报价单发送/客户确认
 → 转订单
```

**报价单字段：**

- 报价单号、客户、图案/版本、布料类型/规格/门幅、颜色、工艺。
- 计价单位：米/码（系统统一换算，订单显示客户常用单位）。
- 数量/长度、单价（元/米或元/码）、金额、损耗率、最低收费、样品费/版费（可选）。
- 交期、结算方式、报价有效期、备注。
- 报价版本、审批状态、客户确认状态、确认时间/附件。

**规则：**

- 报价按长度计价，金额 = 计价长度 × 单价 + 其他费用；支持最低收费和分段计价（可选）。
- 单价低于公司底价/低于成本需要审批；审批金额阈值按组织层级逐级。
- 报价有效期到期提醒；过期报价转订单需重新确认。
- 报价转订单时带出图案、布料、工艺、价格、交期，允许按权限调整。
- 客户确认记录（邮件/微信截图/书面确认）作为附件留存。
- 报价单可复制、版本对比；历史报价不可删除。

### 5.5 合同/价格协议（可选）

- 合同类型：加工合同、框架合同、年度价格协议。
- 合同字段：客户、编号、期限、结算方式、账期、价格条款、质量条款、附件。
- 订单可关联合同；合同金额/剩余额度可作为审批参考。
- 合同到期提醒；变更保留版本。
- 本期不把合同作为订单必填项，按公司实际管理要求启用。

### 5.6 客户 360 视图

一个页面聚合客户全貌：

- 基本信息：来源、归属业务员、等级、结算方式、状态、风险提示。
- 图案：图案列表、版本、最近使用订单。
- 报价：历史报价、待确认、已转订单、报价转化率。
- 订单：在制、待发货、已完成、交期预警。
- 设备：客户名下设备所在工厂、状态、操作员、维保记录。
- 财务：应收余额、逾期、收款记录、对账单。
- 跟进：拜访/电话/线上沟通记录、下次行动。
- 附件：合同、设计确认、质量协议、对账函。

### 5.7 客户跟进与报表

**跟进记录：**

- 方式（拜访/电话/微信/邮件）、时间、联系人、内容、下次计划、附件。
- 业务员可查看自己客户；销售主管查看团队。
- 长期未跟进提醒；报价未确认提醒；订单交期提醒。

**报表：**

- 新增客户、活跃客户、流失客户、客户来源分布。
- 业务员客户数、报价数、成交额、回款额、逾期额。
- 客户订单排行、图案使用排行、返工率、毛利率（按权限）。
- 客户对账单、应收账龄（与财务联动）。

### 5.8 验收要点

- 客户来源、归属业务员必填，数据权限按业务员/团队正确隔离。
- 图案可上传、版本化、预览、权限下载、水印、日志。
- 报价按米/码计价，能计算金额、损耗、最低收费，能审批和转订单。
- 订单必须引用客户和图案版本，换版需变更记录。
- 客户 360 聚合订单、设备、报价、应收，且不泄露其他客户数据。

## 6. 设备管理（客户设备、公司工厂使用）

### 6.1 定位与规则

- 设备所有权归客户，放置在公司不同工厂，由公司专职设备操作员操作。
- 公司不向客户收取设备使用费/托管费；设备使用费不进入订单价格和成本。
- 设备不计入公司固定资产；设备原值如记录，仅作客户资产参考并限制权限。
- 每个工厂管理本厂设备；设备可跨厂移机，但需审批和记录。
- 订单默认使用该客户名下设备；跨客户使用需客户授权和审批（默认禁止）。
- 设备维保由公司设备部门负责，维修成本作为公司内部成本记录；如合同另有约定，可在备注中说明。

### 6.2 设备档案

| 分类 | 字段 |
|---|---|
| 基本信息 | 公司设备编号、客户设备编号、设备名称、类型、型号、序列号、制造商、出厂日期、启用日期 |
| 归属信息 | 所有权=客户、所属客户、客户联系人、设备合同/协议（可选） |
| 位置信息 | 所属工厂、车间/产线、工位、详细位置、移机历史 |
| 状态信息 | 待进场、安装调试、验收中、在用、停机、维修中、封存、待退场、已退场 |
| 技术参数 | 产能、适用布料/门幅、精度、速度、工艺范围、操作要求 |
| 人员信息 | 设备负责人、专职操作员、维保人、客户对接人 |
| 文档 | 说明书、合格证、验收单、维保记录、照片、二维码 |
| 提醒 | 保修到期、保养到期、点检逾期、操作证到期 |

**规则：**

- 设备必须归属客户和工厂，不能无客户、无工厂。
- 设备编号全公司唯一；客户设备编号按客户隔离。
- 设备状态变化、移机、退场、维修全程留痕。
- 设备二维码可用浏览器扫码查看档案/报修（按权限）。

### 6.3 设备进场、移机与退场

**进场：**

```text
业务/设备发起进场申请
 → 设备主管审核
 → 登记设备、配件、外观、照片
 → 客户签字确认
 → 安装调试/验收
 → 分配工厂、车间、操作员
 → 状态“在用”
```

**移机（跨工厂/车间）：**

- 移机申请：原因、原工厂/位置、新工厂/位置、时间、责任人和客户确认。
- 停用原设备 → 拆卸/运输 → 新工厂安装调试 → 验收 → 更新位置。
- 移机期间受影响订单提示重排。
- 跨厂移机需双方厂长/设备主管审批。

**退场：**

- 退场申请 → 检查未结工单、维保、备件、客户物品 → 客户验收 → 放行 → 状态“已退场”。
- 设备档案保留，不删除；退场后不可排产。
- 损坏/缺失责任按客户协议处理，记录备注，不涉及设备使用费。

### 6.4 设备运行与操作员

- 设备状态看板：按工厂、客户、车间、状态筛选。
- 启停记录：开机/停机时间、操作员、停机原因（故障、待料、待单、保养、停电）。
- 工单绑定：订单工单必须选择本厂内该客户的设备，并指派具备资格的操作员。
- 报工记录：生产长度、良品/不良、开始/结束时间、操作员、班次（仅业务记录，不做考勤）。
- 设备运行时长、产量、利用率、故障率统计。
- 设备异常：长时间停机、空转、保养逾期提醒。
- 本期不做设备 IoT 自动采集，后续可扩展。

### 6.5 点检、保养与维修

**点检：**

- 点检模板：日/周/月，检查项、标准、拍照要求。
- 浏览器扫码或页面录入点检结果，异常转维修工单。
- 点检逾期提醒、未点检清单。

**保养：**

- 保养计划：按日历周期或运行时长触发。
- 保养内容、备件、责任人、预计停机时间。
- 自动生成保养工单，完成后记录实际工时、备件、费用、下次保养日期。
- 保养计划与排产联动，提前锁定停机窗口。

**维修：**

```text
报修（操作员/设备主管/客户）
 → 设备主管派工
 → 维修、换件、试机
 → 客户/生产验收
 → 关闭工单
```

- 记录故障类型、原因、处理方案、停机时长、维修成本。
- 备件消耗关联仓库库存；维修成本计入公司内部成本，不向客户收取设备使用费。
- 外委维修记录供应商、报价、审批、费用。
- 维修知识库：故障代码、解决方案、历史案例。

### 6.6 设备产能与排产

- 每台设备维护所属工厂、可用日历、班次、产能（米/小时或件/小时）、换型时间、良率。
- 订单排产只能选择订单生产工厂内、该客户名下、状态可用的设备。
- 设备保养/维修/停机自动占用产能，排产冲突提示。
- 一台设备同一时段原则上只排一个工单；多工位设备可配置并行能力。
- 跨客户使用设备：默认禁止；如确需使用，需客户书面授权 + 双方业务员/厂长/总经理审批。
- 设备故障/移机时提示受影响订单，支持改排、拆分或调整交期。
- 设备产出回写工单进度，订单进度可汇总查看。

### 6.7 设备报表与验收

**报表：**

- 客户设备台账：按客户、工厂、状态、操作员。
- 设备利用率、产量、故障率、停机时长、维修成本。
- 保养计划完成率、点检及时率、维修及时率。
- 设备移机/退场记录、操作员资质到期清单。
- 订单与设备产出对照、客户设备贡献分析。

**验收要点：**

- 设备必须归属客户和工厂，订单工单只能选本厂同客户设备（跨客户需授权）。
- 设备使用不产生任何收费/应付客户费用。
- 操作员资质校验生效，报工记录操作员。
- 设备移机、退场、维修、保养全程可追溯。
- 设备报表可按工厂/客户/状态统计，数据权限正确。

## 7. 订单系统

### 7.1 订单类型

| 类型 | 说明 |
|---|---|
| 布料加工/印花订单 | 主要类型：客户提供图案，公司提供布料并加工，按长度计价 |
| 样品订单 | 打样/试产，单独记录样品费、版费、损耗 |
| 返工订单 | 质量返工，关联原订单/工单，由业务员确认 |
| 补货订单 | 客户追加/补货，可复制历史订单 |
| 其他加工订单 | 特殊工艺/特殊布料，按报价执行 |

### 7.2 订单结构

**订单头：**

- 订单号、订单类型、客户、归属业务员、归属部门。
- 生产工厂、要求交期、承诺交期、发货地址、收货联系人。
- 结算方式、账期、信用占用（可选）、币种、税率。
- 订单总金额、含税/未税、折扣、备注。
- 订单状态、审批状态、生产状态、发货状态、收款状态。
- 附件：客户确认、图案确认、质量要求、原订单（返工）。

**订单行：**

- 行号、图案/版本、布料类型/规格/门幅、颜色/配色、工艺。
- 计价单位（米/码）、计价长度、单价、金额、损耗率、最低收费。
- 交付日期、交付数量/长度、已生产、已入库、已发货、未发货。
- 质量要求、包装要求、客户图案编号。
- 生产工厂、指定客户设备（可拆分工单）。

**生产工单：**

- 工单号、订单行、生产工厂、客户设备、操作员/班组。
- 计划生产长度、计划开始/结束、实际开始/结束。
- 状态：待排产、已排产、待生产、生产中、暂停、待质检、返工中、已完成、已取消。
- 实际产出长度、良品长度、不良长度、报废长度、返工记录。
- 领料记录、报工记录、质检记录、入库记录。

### 7.3 报价转订单

```text
客户确认图案/布料/工艺
 → 业务员创建报价（长度、单价、交期）
 → 报价审批（低于底价/折扣时）
 → 客户确认报价
 → 转订单（带出客户、图案、布料、工艺、价格、交期）
 → 订单审批
 → 排产
```

**规则：**

- 报价按米/码计价；订单可沿用报价单价，也可按权限调整。
- 报价转订单需校验报价有效期、客户确认状态、图案版本。
- 一个报价可拆成多个订单，一个订单也可合并多个报价（需记录关联）。
- 订单金额与报价不一致时，需填写原因并按金额规则审批。

### 7.4 订单创建与校验

提交订单时自动校验：

1. **客户校验**：客户存在、状态正常、归属业务员有效。
2. **图案校验**：图案属于该客户，版本有效，客户已确认。
3. **价格校验**：单价/折扣是否符合报价、底价、审批权限。
4. **信用校验**：如启用信用额度，检查应收/逾期；超限需审批。
5. **工厂校验**：生产工厂启用，工厂内有该客户可用设备。
6. **设备校验**：设备属于该客户、状态可用、无保养/维修/排产冲突。
7. **物料校验**：布料/辅料库存或在途是否满足；缺料提示采购。
8. **产能校验**：按设备产能和交期估算，超负荷提示。
9. **重复校验**：客户图案+布料+颜色+交期重复提醒。
10. **审批校验**：按金额、折扣、变更、返工等触发对应审批链。

### 7.5 订单审批与变更

**审批：**

- 默认按组织架构逐级审批：发起人 → 直属上级 → 上级 → … → 金额规则确定的终审层级。
- 金额阈值由后台手动配置，按业务类型设置不同区间和终审岗位。
- 报价折扣、订单变更、返工确认、采购、付款等可插入业务确认节点。
- 审批通过后订单生效，进入待排产；驳回退回业务员修改。

**订单变更：**

- 可变更：数量/长度、交期、价格、图案版本、布料、颜色、工艺、生产工厂、设备、收货地址。
- 变更单必须记录：变更前后内容、原因、客户沟通、交期/成本/库存影响。
- **业务员确认是必经节点**：业务员确认客户已知悉并同意变更。
- 如变更涉及价格/金额，追加金额审批（按组织层级逐级）。
- 变更通过后，系统更新订单版本、工单、领料、排产、应收计划，并通知生产/仓储/财务。
- 已投产订单变更需评估在制品、已领料、已生产长度；必要时暂停工单。
- 变更历史保留版本，订单详情可查看每次变更和确认记录。
- 订单取消同样需要业务员确认；已投产需生产/仓储/财务确认处理在制品和费用。

### 7.6 订单状态机

```text
草稿
 → 待审批
 → 已确认
 → 待排产
 → 已排产
 → 生产中
 → 待质检
 → 待入库
 → 待发货
 → 部分发货
 → 已完成
 → 已关闭

异常分支：驳回 → 草稿；取消 → 已取消；暂停 → 已排产/生产中；返工 → 返工中 → 待质检
```

**独立状态：**

- 审批状态：未提交、审批中、通过、驳回、撤回。
- 生产状态：未开始、部分完成、已完成、暂停、返工。
- 发货状态：未发货、部分发货、已发货、已签收。
- 收款状态：未收款、部分收款、已收款、逾期。
- 对账状态：未对账、部分对账、已对账。

**规则：**

- 只有“已确认”订单可排产。
- 未质检/未入库不能发货（特殊情况需审批）。
- 发货前校验收款/信用（如启用）；逾期客户需特批。
- 订单完成以交付+签收为准；财务关闭/对账独立控制。
- 状态由业务动作触发，不允许直接修改状态字段。

### 7.7 生产排产

**排产流程：**

```text
订单确认
 → 按订单行/图案/颜色/长度拆分工单
 → 选择生产工厂
 → 选择该客户名下、本厂可用设备
 → 校验设备日历、保养、维修、操作员资质、物料
 → 安排计划开始/结束、操作员、优先级
 → 发布排产计划
 → 通知生产/设备/仓储
```

**排产视图：**

- 设备甘特图：按工厂/设备/时间展示工单、保养、停机。
- 订单视角：订单交期、已排/未排长度、预计完成时间。
- 负荷视图：工厂/设备/班组未来负荷，超负荷提示。
- 冲突检测：设备时间冲突、保养冲突、操作员无资质、物料未齐套。
- 支持手工调整；调整需记录原因并通知相关方。
- 冻结窗口：未来 N 小时内变更需审批（可配置）。

**异常重排：**

- 设备故障、保养超时、缺料、质量异常、急单插入。
- 系统提示受影响订单和交期风险，给出可替代设备/时段建议。
- 重排记录原因，通知业务员/客户（按需）。
- 因客户图案/确认延误导致的待料/停机，记录原因，作为责任分析依据。

### 7.8 生产执行与报工

```text
工单下达 → 领料（公司原材料）→ 生产 → 按长度报工
 → 首件/巡检/终检 → 成品入库 → 工单关闭
```

**领料：**

- 按订单/工单和 BOM 生成领料单；布料按米/码、批次/卷管理。
- 领料出库计入订单材料成本；余料退库；损耗率分析。
- 超领需审批；缺料可部分领料/分批生产，工单标注“待料”。
- 不同工厂库存独立，跨厂用料需先调拨。

**报工：**

- 操作员录入工单、设备、开始/结束、生产长度、良品/不良/报废、停机原因。
- 报工记录操作员、设备、工厂、时间，作为产量、质量和人工成本依据。
- 支持分批报工、补报（需审批）；报工后更新订单进度和设备产量。
- 本期不做考勤，报工时间仅用于生产记录和工时统计。

**质检：**

- 首件检验、过程巡检、成品检验；可配置抽检/全检。
- 检验项、标准、结果、不良代码、照片、检验员。
- 不合格处理：返工、让步接收、报废；返工需业务员确认。
- 质量记录关联订单、工单、设备、图案版本、操作员，支持追溯。

### 7.9 质量返工与业务员确认

**返工流程：**

```text
质检/生产发现不合格
 → 创建返工确认单（订单、工单、数量/长度、不良原因、责任初判）
 → 业务员确认（客户是否知悉、是否同意返工、交期影响、费用承担）
 → 生产制定返工方案 → 返工工单 → 复检
 → 返工完成/报废 → 记录成本与结果
```

**返工确认单字段：**

- 返工单号、原订单/工单、客户、图案版本、不良数量/长度、不良描述、照片。
- 不良原因分类：图案/设计、布料、设备、操作、工艺、客户确认错误、其他。
- 责任归属：公司/客户/供应商/待定。
- 返工方案、预计完成时间、对交期影响。
- 费用承担、是否收费（如客户设计/确认原因）。
- 业务员确认意见、确认时间、客户沟通记录/附件。
- 复检结果、返工成本、关闭时间。

**规则：**

- 业务员确认是返工执行的必经节点；未确认不能开始返工（紧急止损除外，需后补）。
- 返工记录永久保留，关联原订单和质量报表。
- 返工导致交期变化，自动通知业务员和客户（按需）。
- 返工成本计入订单成本；责任为客户的，按公司政策决定是否收费。

### 7.10 发货、签收与退货

- 成品入库后生成发货申请，选择订单行、长度、批次/卷号。
- 发货前校验：质检合格、库存可用、收款/信用（如启用）。
- 出库单/送货单/装箱单，打印或导出；物流信息、运费记录。
- 支持部分发货、多次发货、合并发货。
- 客户签收：页面登记签收人/时间，上传回单；签收后更新交付状态。
- 退货：客户退货申请 → 质量/业务员确认 → 退货入库待检 → 返工/报废/补货。
- 退货关联原订单、发货单、应收/对账，必要时调整应收。

### 7.11 订单成本与毛利（简化）

- 材料成本：布料、墨水、辅料、包材（按领料/批次）。
- 人工成本：报工工时 × 人工费率，或按产量估算。
- 制造费用：工厂水电、设备维修、折旧（公司资产）等分摊（可选）。
- 设备使用费：不纳入（客户设备不收费）。
- 返工/报废/运费/外协费用。
- 订单毛利 =（订单收入 − 订单成本）/ 订单收入。
- 成本数据默认仅财务/管理层可见；业务员可看自己订单的毛利（按授权）。
- 本期成本为管理参考，不做法定总账。

### 7.12 订单报表与验收

**报表：**

- 订单台账、订单进度、交期预警、逾期订单。
- 按业务员/客户/工厂/图案/布料统计订单量、长度、金额。
- 报价转化率、订单变更率、返工率、准时交付率。
- 在制订单、待发货、未收款、对账差异。
- 订单毛利、客户毛利、工厂产出。

**验收要点：**

- 订单必须归属客户和业务员，生产工厂/设备校验生效。
- 报价按长度计算，能转订单并保留图案版本。
- 订单变更必须业务员确认并留记录；价格变化追加金额审批。
- 质量返工必须业务员确认，返工记录完整。
- 排产能校验工厂、客户设备、操作员资质、物料。
- 订单—工单—领料—报工—质检—入库—发货—对账闭环。

## 8. 财务与采购（内部记录，不对接第三方）

### 8.1 定位与边界

财务模块负责公司内部业务财务记录：

- 客户应收、收款、对账、账龄。
- 供应商应付、原材料采购、付款。
- 资金账户/流水（手工登记）。
- 费用支出（可选）。
- 订单成本/毛利（管理参考，可选）。
- **不做**：银行直连、电子发票接口、税控、总账凭证、税务申报、第三方财务软件对接。

**角色分离：**

- 采购：供应商、采购订单、到货跟踪。
- 仓管：采购入库、库存。
- 财务：应收应付、收付款、对账。
- 出纳：付款执行/收款登记（可按公司实际配置）。
- 审批人：按组织层级和金额规则审批。

### 8.2 供应商与原材料采购

**供应商档案：**

- 供应商编码、名称、联系人、电话、地址、结算方式、账期、开票信息、银行账户、状态。
- 供应类别：布料、墨水、辅料、包材、设备备件、外协服务。
- 供应商报价/价格协议（可选）、历史采购、应付余额。

**采购流程：**

```text
采购申请（生产/仓储/设备）
 → 采购询价/比价（可选）
 → 采购订单
 → 到货 → 仓库收货/质检
 → 采购入库
 → 应付登记
 → 付款申请 → 逐级审批 → 付款记录
```

**采购字段：**

- 采购单号、供应商、采购类型、需求工厂/仓库、需求日期。
- 采购行：物料、规格、数量、单位、单价、金额、税率、交期。
- 关联采购申请、合同/报价、到货入库单。
- 状态：草稿、待审批、已下单、部分到货、已到货、已入库、已关闭、已取消。

**规则：**

- 采购必须关联供应商、物料、需求工厂/仓库。
- 采购金额按组织层级逐级审批，金额阈值后台配置。
- 到货数量与采购数量差异记录；超收/短收需处理。
- 采购入库后形成应付；付款需关联采购/入库/发票（如有）。
- 原材料由公司采购，不允许客供料入库（本期）。

### 8.3 客户应收、收款与对账

**应收：**

- 来源：订单/发货/对账单；可手工新增其他应收。
- 字段：客户、订单、金额、已收、未收、到期日、业务员、状态。
- 收款状态：未收款、部分收款、已收款、逾期。

**收款：**

- 收款登记：客户、金额、日期、方式（银行/现金/承兑/其他）、账户、流水号、附件。
- 核销：按订单/应收单核销，支持部分核销、多笔合并、预收款。
- 未核销收款进入“待认领”，财务后续分配。
- 收款后更新客户应收余额、订单收款状态。

**对账：**

- 按客户/期间生成对账单：期初、订单/发货、收款、期末。
- 对账单发送/打印，客户确认后归档；差异记录原因。
- 支持按订单明细对账、按汇总对账。
- 对账差异关联订单/收款，处理后可重新生成。

**账龄：**

- 0–30、31–60、61–90、90 天以上。
- 逾期提醒业务员/财务；催收记录（可选）。
- 信用额度（可选）：超限阻断下单/发货，需审批。

### 8.4 应付、付款与费用

**应付：**

- 来源：采购入库、外协/维修、费用报销、其他。
- 字段：供应商、来源单据、金额、已付、未付、到期日、状态。

**付款：**

- 付款申请：供应商、应付单、金额、付款方式、账户、附件。
- 按组织层级+金额阈值审批；财务复核；出纳/财务登记付款。
- 付款后核销应付；支持预付款、部分付款。
- 付款记录包含流水号、日期、账户、经办人、审批单号。
- 本期不对接银行，付款结果手工登记。

**费用：**

- 费用类型：房租、水电、物流、差旅、办公、维修、其他。
- 费用登记/报销：金额、日期、部门/工厂、供应商/个人、发票/附件。
- 费用审批按金额规则；付款后核销。
- 费用可按工厂/订单/部门分摊（可选）。

### 8.5 资金账户与流水

- 银行账户、现金账户、其他账户；账户名称、账号、开户行、期初余额。
- 资金流水：收款、付款、内部转账、手续费、利息。
- 账户余额 = 期初 + 收入 − 支出；支持按日期/账户查询。
- 资金日报/月报；账户余额预警（可选）。
- 不对接银行，流水由财务手工登记/导入（Excel）。
- 收款/付款必须关联业务单据或填写明确用途。

### 8.6 成本与报表

**成本（可选/逐步完善）：**

- 订单材料成本（领料）、人工成本（报工）、制造费用分摊、返工/报废/运费。
- 不含客户设备使用费。
- 订单毛利、客户毛利、工厂毛利。

**报表：**

- 客户应收明细/汇总、账龄、收款记录、对账单。
- 供应商应付、采购明细、付款记录、供应商对账。
- 采购金额/数量、原材料价格趋势、供应商交付。
- 资金流水/余额、费用明细。
- 订单毛利、工厂成本（按权限）。
- 业务员回款业绩、客户欠款排行。

### 8.7 财务规则与验收

**规则：**

- 财务单据不物理删除；错误用红冲/作废并留原因。
- 收款/付款必须关联业务依据；无依据需特批。
- 采购、入库、应付、付款形成闭环；数量/金额可核对。
- 审批与执行分离；付款审批人不能同时是唯一执行人（可配置）。
- 对账单、付款凭证、发票（如有）作为附件留存。
- 月末可做客户/供应商对账和期间锁定（可选）。

**验收要点：**

- 客户订单—发货—应收—收款—对账链路完整，金额一致。
- 采购申请—采购订单—入库—应付—付款闭环。
- 支持部分收款/付款、预收/预付、多笔核销。
- 对账单能按客户/期间生成并记录确认。
- 没有第三方接口依赖，所有数据在系统内可查。
- 成本/毛利数据按权限隔离。

## 9. 流程审批

### 9.1 定位

统一审批中心承载全系统审批。审批与业务单据解耦：业务单据提交后生成审批实例，审批结果回写业务状态。

**覆盖场景：**

- 客户：新建/变更、归属业务员变更、信用额度（如启用）、客户合并/冻结。
- 报价/订单：报价审批、订单确认、价格折扣、订单变更、订单取消、急单、返工确认。
- 设备：进场、移机、退场、维修、外委维修、跨客户使用授权。
- 仓储：跨厂调拨、库存调整、盘点差异、报废、其他出入库。
- 采购/财务：采购申请、采购订单、付款、费用、对账差异、坏账（可选）。
- 权限：角色授予、临时授权、数据权限变更。
- 人事：入职、转正、调岗/调厂、离职（不含考勤类审批）。

### 9.2 审批层级与金额规则

**默认规则：按公司组织架构逐层审批，不跳级。**

```text
发起人
 → 直属上级
 → 上级的上级
 → ……
 → 金额规则/业务类型确定的终审层级
```

**金额规则后台手动配置：**

| 配置项 | 说明 |
|---|---|
| 业务类型 | 报价、订单、采购、付款、费用、调拨、返工等 |
| 金额区间 | 如 0–5,000、5,000–20,000、20,000–50,000、50,000 以上 |
| 终审层级/岗位 | 主管、部门负责人、厂长、总经理等 |
| 是否逐层 | 默认是；从发起人上级逐层到终审层级 |
| 是否插入财务/采购复核 | 如付款必须有财务复核，可配置 |
| 生效范围 | 全公司/指定工厂/指定部门 |
| 生效时间 | 立即或指定日期 |

**示例（金额仅为示意，需按公司制度设置）：**

| 业务 | 金额区间 | 终审层级 |
|---|---|---|
| 报价折扣 | 低于底价 5% 以内 | 销售主管 |
| 报价折扣 | 低于底价 5%–10% | 销售负责人 |
| 订单 | 0–20,000 | 部门负责人 |
| 订单 | 20,000–100,000 | 厂长/销售负责人 |
| 订单 | 100,000 以上 | 总经理 |
| 采购/付款 | 0–10,000 | 部门负责人 + 财务复核 |
| 采购/付款 | 10,000–50,000 | 厂长/财务负责人 |
| 采购/付款 | 50,000 以上 | 总经理 |

**规则：**

- 审批链按单据提交时的组织架构快照生成，后续组织调整不影响已发起单据。
- 发起人本人是审批节点时自动跳过，避免自己批自己。
- 上级为空时按配置：跳过/转交指定人/阻断，需提前设置。
- 业务员确认（订单变更、返工）作为必经节点插入，不替代金额审批。
- 财务复核、仓库确认、设备主管确认等可作为业务节点。
- 审批金额阈值修改需权限和审计；修改前已发起单据不受影响。

### 9.3 审批操作与记录

- 我的待办、我发起的、已办、抄送。
- 同意、驳回、撤回、转办、加签（可选）、催办。
- 驳回必须填写原因；撤回仅限未被处理的节点。
- 审批意见、附件、时间戳不可篡改。
- 审批通过/驳回后回写业务状态；驳回后退回发起人修改。
- 审批记录在业务单据详情中展示时间轴。
- 支持按业务类型/发起人/审批人/时间查询。
- 审批效率统计：平均时长、节点耗时、驳回率、超时。

### 9.4 审批场景矩阵

| 场景 | 发起人 | 审批链（默认逐层） | 关键校验 |
|---|---|---|---|
| 报价审批 | 业务员 | 直属上级 → 销售负责人（按折扣/金额） | 底价、毛利率、图案版本 |
| 订单确认 | 业务员 | 直属上级 → 部门/工厂 → 金额终审 | 客户、价格、交期、设备、物料 |
| 订单变更 | 业务员 | 业务员确认 → 直属上级 → 金额终审 | 变更影响、客户确认、价格 |
| 订单取消 | 业务员 | 业务员确认 → 主管 → 生产/仓储/财务 → 终审 | 在制、领料、费用 |
| 质量返工 | 生产/质检 | 业务员确认 → 生产主管 → 厂长（重大） | 不良原因、责任、交期、费用 |
| 设备进场/移机/退场 | 设备/业务 | 设备主管 → 厂长 → 总经理（跨厂/重大） | 客户确认、未结工单、位置 |
| 跨客户设备使用 | 生产 | 双方业务员 → 双方厂长 → 总经理 | 客户书面授权、设备归属 |
| 跨厂调拨 | 仓管/工厂 | 调出仓管 → 调出厂长 → 调入厂长 → 财务（金额） | 库存、在途、接收 |
| 库存调整/盘点差异 | 仓管 | 仓库主管 → 厂长 → 财务 | 差异金额、原因、证据 |
| 采购申请/订单 | 采购/生产/仓储 | 直属上级 → 厂长 → 采购负责人 → 金额终审 | 需求、预算、供应商 |
| 付款 | 采购/财务 | 财务复核 → 直属上级 → 金额终审 → 出纳执行 | 采购/入库/应付、账户 |
| 费用 | 员工 | 直属上级 → 财务 → 金额终审 | 发票、标准、预算 |
| 客户归属变更 | 销售主管 | 原业务员 → 新业务员 → 销售负责人 | 交接、未结订单、应收 |
| 权限授予 | 部门/工厂负责人 | 系统管理员 → 信息安全（可选） | 最小权限、期限 |

### 9.5 验收要点

- 审批链默认按组织架构逐层向上，不跳级；发起人本人节点自动跳过。
- 金额区间、终审层级可在后台手动配置，修改有审计。
- 业务员确认节点在订单变更/返工中强制生效。
- 审批结果正确回写业务状态；驳回/撤回能回滚业务占用。
- 审批记录完整可追溯；PC 页面操作顺畅，无需移动端或小程序。

## 10. 仓储系统

### 10.1 库存模型

**基础档案：**

- 工厂 → 仓库 → 库区/库位。
- 仓库类型：原料仓、成品仓、辅料仓、待检仓、不良品仓、报废仓、备件仓。
- 物料：编码、名称、规格、单位、分类、批次管理、卷/匹管理、安全库存、默认仓库。
- 库存维度：

```text
工厂 + 仓库 + 库位 + 物料 + 批次/卷号 + 库存状态
```

**单位与计量：**

- 布料按米/码计量，支持小数；采购/库存/订单单位可换算。
- 卷/匹管理：记录卷号、批次、初始长度、剩余长度、门幅、颜色。
- 辅料/墨水按数量/重量；成品按米/码/卷。
- 负库存默认禁止；特殊调整需审批。
- 库存成本：移动加权平均/批次成本（按物料配置）；客供料不适用。

### 10.2 入库管理

| 类型 | 来源 | 关键点 |
|---|---|---|
| 采购入库 | 采购订单/到货单 | 供应商、批次、卷号、长度、质检 |
| 生产入库 | 工单/订单 | 良品长度、不良、批次/卷、质检 |
| 退货入库 | 客户退货 | 待检、原因、原订单 |
| 调拨入库 | 跨厂调拨 | 在途、接收确认、差异 |
| 其他入库 | 盘盈、样品、赠品 | 原因、审批 |

**流程：**

```text
到货/入库通知 → 收货 → 质检（可选）→ 上架 → 库存台账
```

- 采购收货核对供应商、物料、数量/长度、批次、卷号、外观。
- 支持浏览器+扫码枪扫描物料/卷标签；不依赖 PDA。
- 短收/溢收/破损/错货记录差异并处理。
- 质检不合格进入待检/不良品仓，不参与可用库存。
- 生产入库关联工单/订单，记录良品/不良长度。
- 入库单审核后库存增加；红冲需审批。

### 10.3 出库管理

| 类型 | 用途 | 关键点 |
|---|---|---|
| 生产领料 | 工单/BOM | 布料按卷/批次、长度；余料退库 |
| 销售出库 | 订单/发货单 | 质检、收款/信用、物流 |
| 调拨出库 | 跨厂调拨 | 在途、调入方接收 |
| 报废出库 | 不良/过期 | 审批、原因、照片 |
| 其他出库 | 样品、借用、赠品 | 审批、用途 |

**流程：**

```text
出库申请 → 审批（按类型/金额）→ 拣货 → 扫码复核 → 出库 → 库存台账
```

- 布料按卷/批次出库，记录实际长度；剩余长度回写卷档案。
- 生产领料按 BOM/工单，超领需审批；余料退库。
- 销售出库校验订单、质检、库存、收款/信用（如启用）。
- 支持部分出库、多次发货。
- 出库复核：物料、长度、卷号、批次、包装、标签。

### 10.4 跨工厂调拨

```text
调出工厂发起调拨申请
 → 调出仓管/厂长审批
 → 调入工厂确认需求
 → 调出仓库出库（在途）
 → 运输
 → 调入工厂收货/质检
 → 调入仓库入库
 → 差异处理
```

**规则：**

- 调拨单必须标明调出工厂/仓库、调入工厂/仓库、物料、批次/卷、长度、原因。
- 调拨审批可按金额/数量配置，默认双方厂长确认。
- 在途库存单独标识，不参与调出/调入可用库存。
- 调入方收货数量/长度与调拨单差异需记录，责任方处理。
- 跨厂调拨不产生销售/采购，内部结算可选（本期不做 internal billing）。
- 调拨记录同时出现在两个工厂的库存台账。

### 10.5 盘点与库存调整

- 盘点类型：全盘、抽盘、循环盘点；按工厂/仓库/物料/批次/卷。
- 盘点可冻结库存或动态盘点（配置）。
- 生成盘点表 → 扫码/手工盘点 → 复盘 → 差异审批 → 库存调整。
- 差异原因：收发错误、损耗、计量误差、丢失、系统错误。
- 盘盈/盘亏、质量降级、批次转换、报废均需审批并留痕。
- 库存冻结/解冻用于质量、客户争议、法律场景。

### 10.6 批次、卷号与追溯

- 布料批次/缸号、卷号、门幅、颜色、长度、供应商、入库日期。
- 成品批次/卷号关联订单、图案版本、工单、设备、操作员。
- 正向追溯：原料批次 → 生产工单 → 成品卷 → 客户/发货。
- 反向追溯：客户投诉/退货 → 成品卷 → 工单/设备/操作员 → 原料批次。
- 余料/尾卷管理：记录剩余长度，可用于小单/样品。
- 临期/长期呆滞提醒（如适用）。

### 10.7 与订单/生产联动

- 订单确认后按 BOM 检查布料/辅料库存；缺料提示采购。
- 工单下达生成领料需求，按工厂仓库预留。
- 领料单关联工单，记录卷号/批次/长度/金额。
- 超领、补料、退料、替代料需审批/记录。
- 成品入库关联工单，更新订单已生产长度。
- 发货出库关联订单/发货单，更新已发货长度。
- 订单变更/取消时释放预留、退料、调整库存。
- 跨厂生产时，物料先调拨到生产工厂。

### 10.8 库存预警与报表

**预警：**

- 低于安全库存、呆滞、临期/过期。
- 负库存、库存与订单预留冲突。
- 盘点差异超阈值、库存金额异常波动。
- 调拨在途超期未接收。

**报表：**

- 库存余额表（工厂/仓库/物料/批次/卷/状态）。
- 出入库明细、库存台账、收发存汇总。
- 库存周转率、呆滞分析、ABC 分析、库龄。
- 安全库存预警、缺料清单、临期清单。
- 跨厂调拨明细、在途清单、差异。
- 盘点差异、报废、调整明细。
- 库存金额与财务成本核对（按权限）。

### 10.9 扫码与打印

- 物料标签、卷标签、库位标签、托盘标签、设备二维码。
- 浏览器 + 扫码枪完成收货、上架、拣货、复核、盘点。
- 打印送货单、领料单、调拨单、盘点表、标签。
- 不做 PDA 专用客户端、小程序或独立 App；扫码使用浏览器 + 扫码枪。

### 10.10 验收要点

- 每个工厂库存独立，跨厂调拨有在途和接收确认。
- 布料按米/码、批次/卷管理，余料可追溯。
- 采购入库—生产领料—成品入库—销售出库闭环。
- 库存只能通过单据变动，台账可追溯。
- 盘点差异必须审批后调整。
- 库存预警、缺料提示能影响排产和采购。

## 11. 首页大屏与管理驾驶舱

### 11.1 定位

首页是角色化工作台 + 经营驾驶舱：

- 员工打开系统先看到待办和异常。
- 管理层看到经营、工厂、订单、设备、库存、财务健康度。
- 大屏用于会议室/展厅/工厂现场展示。

### 11.2 核心指标

**经营：**

- 本月/本年订单额、营收（按发货/对账口径）、收款、应收余额、逾期应收。
- 订单数、完成订单、在制订单、准时交付率、订单变更率、返工率。
- 客户新增、活跃、流失、客户来源分布、业务员业绩。
- 报价数、报价转化率、平均报价金额。

**工厂/生产：**

- 各工厂订单量、产量（米/码）、计划达成率、良品率、返工率。
- 在制工单、待排产、缺料工单、延期工单。
- 设备总数、在用/停机/维修、设备利用率、故障率、停机时长。
- 客户设备分布、操作员工作量、维保计划完成率。

**仓储/采购：**

- 各工厂库存金额/数量、库存周转、呆滞、缺料预警。
- 跨厂调拨在途、待接收。
- 采购在途、到货及时率、供应商交付、原材料价格趋势。

**财务：**

- 应收账龄、逾期客户、收款趋势、对账差异。
- 应付余额、付款计划、资金余额。
- 订单毛利、客户毛利、工厂成本（按权限）。

**流程/风险：**

- 待审批数量、超时审批、平均审批时长。
- 交期预警、设备故障、库存预警、应收逾期。

### 11.5 KPI 口径

| 指标 | 口径 |
|---|---|
| 订单准时交付率 | 按期交付订单行 / 期间交付订单行 × 100% |
| 报价转化率 | 转订单报价数 / 已确认报价数 × 100% |
| 订单变更率 | 发生变更订单数 / 已确认订单数 × 100% |
| 返工率 | 返工长度 / 生产总长度 × 100% |
| 设备利用率 | 实际运行时间 / 计划可用时间 × 100% |
| 设备故障率 | 故障停机时间 / 计划运行时间 × 100% |
| 库存周转率 | 期间销货成本 / 平均库存金额 |
| 库存准确率 | 盘点账实相符项数 / 盘点总项数 × 100% |
| 应收逾期率 | 逾期应收金额 / 应收总额 × 100% |
| 采购到货及时率 | 按期到货采购行 / 到货采购行 × 100% |
| 订单毛利率 |（订单收入 − 订单成本）/ 订单收入 × 100% |
| 审批及时率 | SLA 内完成审批数 / 总审批数 × 100% |

**口径原则：**

- 明确期间、含税/未税、是否含取消订单、按订单头/行。
- 财务口径以收付款/对账记录为准；生产以报工/入库为准。
- 指标说明在系统内维护，避免口径不一致。

### 11.6 预警与验收

**预警：**

- 订单交期、设备故障/保养、库存缺料/呆滞、应收逾期、采购到货、审批超时。
- 预警接收人按角色/工厂配置；支持站内消息/待办。

**验收要点：**

- 不同角色看到不同首页，工厂/业务员数据隔离正确。
- 指标与业务报表一致，口径可说明。
- 大屏可全屏、自动刷新、适配常见分辨率。
- 敏感数据不出现；大屏账号权限正确。
- 预警可跳转到业务单据处理。

## 12. 跨模块核心场景

### 12.1 新客户 + 图案 + 报价 + 首单

```text
1. 业务员新建客户，填写客户来源、归属业务员、联系人、结算方式
2. 客户提供图案 → 上传图案文件、登记颜色/工艺/版本 → 客户确认
3. 业务员按布料长度报价：选择图案、布料、门幅、工艺、长度、单价
4. 报价审批（低于底价/折扣）→ 客户确认报价
5. 报价转订单：选择生产工厂、交期、收货地址
6. 订单审批：按组织层级逐级 + 金额阈值
7. 排产：选择该客户在本厂设备，指派有资格的操作员
8. 领料：公司原材料从本厂仓库出库，布料按卷/批次/长度
9. 生产报工：按长度记录良品/不良，质检
10. 不合格返工：业务员确认客户知悉/同意，返工后复检
11. 成品入库 → 发货 → 客户签收
12. 财务：形成应收 → 收款登记 → 对账 → 订单关闭
```

### 12.2 订单变更（业务员确认）

```text
生产/业务发现需变更（长度、交期、图案版本、布料、颜色、工艺等）
 → 创建订单变更单，记录变更前后、原因、影响
 → 业务员确认（客户已知悉并同意，上传沟通记录）
 → 涉及价格/金额：追加逐级金额审批
 → 生产/仓储/财务评估在制、领料、交期、应收
 → 审批通过 → 更新订单版本/工单/排产/应收
 → 通知相关方，保留变更记录
```

### 12.3 质量返工（业务员确认）

```text
质检发现不合格 → 创建返工确认单
 → 记录不良长度、原因、照片、责任初判
 → 业务员确认（客户是否知悉、是否同意返工、交期/费用影响）
 → 生产制定返工方案 → 返工工单 → 复检
 → 返工完成/报废 → 成本归集 → 质量报表
```

### 12.4 跨工厂调货

```text
工厂 A 库存不足 / 工厂 B 有富余
 → 工厂 A 发起跨厂调拨申请
 → 调出/调入厂长审批
 → 工厂 B 仓库出库（在途）
 → 运输
 → 工厂 A 收货、质检、入库
 → 双方库存台账更新；差异处理
```

### 12.5 设备故障影响订单

```text
操作员/设备主管报修 → 维修工单
 → 设备标记停机 → 受影响工单/订单交期预警
 → 生产重排（同厂其他客户设备不可随意用；需客户授权）
 → 通知业务员/客户
 → 维修完成试机 → 设备恢复 → 工单继续
 → 维修成本内部记录，不向客户收设备使用费
```

### 12.6 原材料采购到付款

```text
生产/仓储提出采购申请
 → 采购询价/比价（可选）
 → 采购订单审批（逐级 + 金额）
 → 供应商发货 → 工厂仓库收货/质检 → 采购入库
 → 财务登记应付
 → 付款申请 → 财务复核 → 逐级审批 → 付款记录
 → 供应商对账
```

### 12.7 月度客户/供应商对账

```text
财务选择客户/期间 → 生成对账单（订单、发货、收款）
 → 业务员核对 → 客户确认 → 差异处理 → 归档
供应商对账：采购、入库、付款 → 供应商确认 → 差异处理
 → 更新应收/应付余额
```

### 12.8 员工离职/调岗

```text
离职/调岗审批 → 客户交接（业务员）→ 订单/设备/资料交接
 → 账号停用/角色调整 → 权限回收
 → 历史订单/审批保留原归属记录
```

### 12.9 权限调整

```text
部门/工厂权限模板调整 → 预览受影响用户
 → 权限审批 → 生效 → 通知用户
 → 保留权限快照 → 审计可查
```

**关键字段建议：**

- 所有业务单据：编号、状态、创建人、创建时间、所属工厂、所属部门、备注、附件。
- 客户/订单/设备/库存：必须带 `factory_id`，用于工厂数据隔离。
- 图案/订单行：必须带 `design_id` + `design_version`。
- 报价/订单行：`unit`（米/码）、`quantity`（长度，decimal）、`unit_price`、`amount`、`loss_rate`。
- 审批实例：`business_type`、`business_id`、`amount`、`org_snapshot`、`current_node`。
- 库存：`warehouse_id`、`material_id`、`batch_no`、`roll_no`、`length`、`status`、`owner_type`（本期仅公司）。

## 14. 非功能性需求与部署

### 14.1 公网域名部署

- 使用公司自有/租赁域名，配置 HTTPS 证书。
- 部署在云服务器或 IDC，所有工厂通过互联网浏览器访问。
- 如服务器位于中国大陆，需按法规完成 ICP 备案；域名、SSL 证书提前准备。
- 建议架构：Nginx/网关 → 应用服务 → 数据库 → 对象存储（图案/附件）→ 备份。
- 公网入口建议启用 WAF、防火墙、登录失败锁定、强密码；管理员可限定 IP。
- 所有工厂不需要专线/VPN 即可访问；如公司要求更高安全，可增加 VPN/零信任（可选）。
- 不需要小程序、独立 App、PDA 客户端；PC 浏览器（Chrome/Edge）为主，页面可做基础响应式适配。

### 14.2 多工厂数据隔离

- 工厂是核心数据隔离维度：订单、工单、设备、仓库、库存、用户。
- 总部/总经理/财务可按授权跨厂；工厂用户默认只看本厂。
- 跨厂调拨、跨厂查看、跨客户设备使用需单独授权。
- 数据权限在接口层校验，不能只靠前端隐藏菜单。
- 大屏/报表按工厂范围过滤，避免汇总泄露。

### 14.3 安全与合规

- 全站 HTTPS；密码策略、登录失败锁定、会话超时。
- 敏感字段加密/脱敏：客户联系方式、价格/成本、供应商报价、员工身份证/银行卡。
- 图案文件访问鉴权、下载水印、下载日志；防止客户设计外泄。
- 防 SQL 注入、XSS、CSRF、越权访问；文件上传类型/大小限制。
- 操作日志、登录日志、导出日志保留不少于 3 年（按公司制度）。
- 本期不采集考勤定位/人脸，减少个人信息合规风险；员工身份证等非必要不采集。
- 备份：每日全量 + 增量，异机/异地保留；定期恢复演练。
- 离职账号及时停用；权限定期复核；付款审批与执行分离。

### 14.4 性能与可用性

- 按公司实际用户数/工厂数设定并发目标（建议 100–300 并发，按需调整）。
- 常用列表/详情 < 2 秒；复杂报表 < 5 秒；大屏首屏 < 3 秒。
- 图案文件使用对象存储，避免大文件拖慢业务库。
- 订单、库存台账、审批日志按年增长，支持归档/分区。
- 业务时段可用性 ≥ 99.5%；关键数据每日备份。
- 浏览器兼容：Chrome/Edge 最近两个大版本；不支持 IE。

### 14.5 集成与扩展

- 本期不接第三方财务/银行/发票系统；如后续需要，预留接口。
- 可扩展：设备 IoT、电子签章、开放接口；不改变本期“后台 + Web 页面”的使用方式。
- 开放 API/Webhook 可按需后续建设。
- 自定义字段、编码规则、打印模板尽量配置化。

## 15. 实施规划

### 15.1 优先级

| 优先级 | 模块/能力 | 说明 |
|---|---|---|
| P0 | 工厂/组织/员工/权限、客户/来源/归属、图案库、报价、设备档案、仓库/库存基础、审批引擎 | 系统骨架和主数据 |
| P0 | 订单基础、工单/排产、领料/报工/质检、跨厂调拨、应收/收款、采购/应付/付款 | 核心业务闭环 |
| P0 | 公网域名部署、账号安全、操作日志、基础报表 | 上线必备 |
| P1 | 订单变更/返工确认、客户 360、设备维保、盘点、对账单、首页驾驶舱 | 管理深化 |
| P1 | 成本/毛利、供应商对账、库存预警、大屏 | 经营分析 |
| P2 | 设备 IoT、电子签章、消息通知、高级排程、开放接口 | 后续扩展 |

### 15.2 阶段建议

**阶段 0：需求确认与原型（2–3 周）**

- 确认剩余问题（见第 16 节）。
- 输出页面原型：客户/图案/报价、订单、排产、设备、库存调拨、收付款、审批、权限、大屏。
- 确定工厂/部门/角色/审批金额规则。

**阶段 1：基础平台 + 主数据（4–6 周）**

- 工厂、组织、员工、账号、权限。
- 客户、来源、归属业务员、图案库、报价。
- 设备档案、仓库/库位、物料、供应商。
- 审批引擎、编码/字典/附件/日志。
- 公网环境、域名、HTTPS、备份。

**阶段 2：订单—生产—仓储—财务闭环（6–8 周）**

- 订单、订单变更、工单、排产、领料、报工、质检、返工确认。
- 成品入库、发货、签收、退货。
- 跨厂调拨、盘点、库存台账。
- 应收/收款/对账、采购/应付/付款。
- 首页工作台 V1。

**阶段 3：管理深化（4–6 周）**

- 客户 360、设备维保、库存预警、供应商对账。
- 成本/毛利、业务员/工厂报表、大屏。
- 权限复核、审计报表。

**阶段 4：扩展（持续）**

- IoT、电子签章、消息通知、高级排程、开放接口等。

> 时间为建议，实际取决于团队规模、确认速度和数据准备。

### 15.3 上线与数据准备

- **无旧系统数据迁移**：不执行历史数据导入。
- 上线前录入：工厂、部门、岗位、员工/账号、角色权限、客户、来源、业务员、图案、设备、仓库/库位、物料、供应商、期初库存、期初应收/应付（如有）。
- 期初库存/往来需财务确认，作为建账基准。
- 选 1 个工厂/1–2 个业务员/少量客户试点，跑通“图案—报价—订单—生产—入库—发货—收款”。
- 试点通过后推广到其他工厂；分角色培训（业务员、厂长、生产、设备、仓管、采购、财务、管理员）。
- 上线支持期收集问题，按 P0/P1 修复。

### 15.4 风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| 多工厂权限复杂 | 数据串厂/越权 | 工厂为硬隔离维度；模板+预览+定期复核 |
| 图案文件泄露 | 客户知识产权风险 | 权限、水印、下载日志、对象存储私有访问 |
| 按长度计价/损耗争议 | 金额/成本不准 | 明确单位、损耗率、最低收费、四舍五入规则 |
| 设备归属/跨客户使用 | 客户纠纷 | 默认同客户设备；跨客户需书面授权+审批 |
| 审批逐层过多 | 效率低 | 合理设置金额阈值/终审层级；超时提醒；避免无效节点 |
| 订单变更/返工确认不及时 | 交期/成本失控 | 业务员确认设为必经节点；超时升级；记录影响 |
| 公网安全 | 数据泄露/攻击 | HTTPS、WAF、强密码、最小权限、备份、日志 |
| 基础数据质量 | 报表/流程错误 | 主数据责任人、导入校验、上线前核对 |
| 需求蔓延 | 延期 | P0/P1/P2 分级，变更评审 |

## 16. 已确认事项与剩余待确认问题

### 16.1 已确认（本版已落地）

1. 客户设备放在公司不同工厂，每厂有仓储；可跨厂调货；公司专职操作员操作；不收费。
2. 客户设计图案，业务员按布料长度报价；原材料公司提供。
3. 财务不做第三方对接；负责客户收付款记录、对账、原材料采购。
4. 删除员工考勤功能。
5. 审批按组织架构逐层；审批金额可后台手动设置。
6. 客户来源记录；销售归属业务员。
7. 订单变更、质量返工由业务员确认并记录。
8. 公网域名部署，所有工厂可登录。
9. 不做小程序；后台 + Web 页面。
10. 无旧系统数据，不做迁移。

### 16.2 剩余待确认

1. **设备维保费用**：设备使用不收费已确认；维保/维修/备件费用是否全部由公司承担？客户原因损坏是否赔偿？
2. **跨客户设备使用**：是否绝对禁止，还是允许在客户书面授权下使用？审批层级？
3. **订单生产工厂**：一个订单是否允许拆分到多个工厂生产？还是必须单工厂？
4. **审批金额规则**：各业务类型的金额区间、终审层级（主管/部门/厂长/总经理）具体数值。
5. **财务范围**：是否需要信用额度管理、开票记录（手工）、费用报销、订单成本/毛利？
6. **合同管理**：是否需要正式合同/价格协议，还是报价+订单即可？
7. **期初数据**：无旧系统，但期初库存、期初应收/应付是否需要录入？
8. **图案保密**：是否需要水印、禁止下载、仅在线预览？设计文件保存多久？
9. **员工自助**：员工是否需要登录查看个人信息/审批，还是只有管理员后台？
10. **单位与精度**：布料按米还是码为主？长度小数位、损耗率、最低收费规则？
11. **工厂层级**：公司下是否还有区域/事业部？工厂与部门的具体层级。
12. **域名/备案**：域名是否已有？服务器在中国大陆还是境外？是否已完成 ICP 备案？
