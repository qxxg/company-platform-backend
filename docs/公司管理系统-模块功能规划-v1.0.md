## 1. 项目概述

### 1.1 建设目标

建设一套覆盖 **“人、客、单、机、料、财、审、数”** 的一体化运营管理系统，把目前可能分散在 Excel、微信群、纸质单据中的业务流程统一到同一平台：

1. **业务全链路在线**：客户 → 合同 → 订单 → 排产 → 生产/报工 → 质检 → 入库 → 发货 → 对账开票 → 回款 → 订单关闭，全流程可追踪。
2. **客户设备可管控**：设备所有权归客户，但公司可对设备档案、安装位置、运行、维保、产能和订单生产进行统一管理。
3. **权限精细可控**：支持按部门、岗位、角色、人员、字段、数据范围进行后台手动配置，重要数据“看得见的人才能看”。
4. **业财一体化**：业务单据自动形成应收、应付、成本与资金数据，减少重复录入，保证账实一致。
5. **管理可视化**：为不同角色提供工作台，为管理层提供经营驾驶舱和可投屏的首页大屏。
6. **过程可审计**：审批、权限变更、库存调整、财务红冲等关键动作全部留痕。

### 1.2 核心业务主线

```text
客户建档/审核
   ↓
合同/价格协议
   ↓
销售订单（订单必须归属客户）
   ↓
订单审批（金额、折扣、信用、设备归属校验）
   ↓
生产排产（绑定该客户名下设备）
   ↓
领料/生产/报工/质检（使用客户设备）
   ↓
成品入库 → 发货/签收
   ↓
应收账款 → 开票 → 收款核销 → 订单关闭
```

贯穿全流程的支撑能力：

- **设备线**：客户设备进场 → 安装验收 → 运行/点检/保养/维修 → 移机/退场。
- **仓储线**：采购入库、客供料入库、生产领料、成品入库、销售出库、调拨、盘点。
- **财务线**：应收、应付、费用报销、资金、成本核算、对账、结账。
- **人事线**：组织、员工档案、排班、打卡、请假、加班、出差、考勤汇总。
- **审批线**：所有业务单据可配置审批流，支持会签、或签、条件分支、转办、加签。
- **权限线**：部门权限模板 + 角色权限 + 用户例外 + 字段/数据权限。

### 1.3 关键业务假设（需业务确认）

由于“设备属于客户、订单由客户设备制作”是本系统最特殊的业务约束，先按以下假设设计，后续可调整：

1. **设备所有权**：设备所有权始终归客户，系统记录“所有权 + 保管责任 + 使用责任”，**不计入公司固定资产**；如需计值，仅作为客户资产参考值并做权限隔离。
2. **设备位置**：支持两种模式——客户设备放在公司场地托管生产，或公司人员驻客户现场使用客户设备生产。系统用“安装地点类型 + 详细地址 + 责任部门/责任人”区分。
3. **订单与设备绑定**：订单只能使用**该订单客户名下**的设备；确需跨客户借用设备时，必须走“设备借用/授权”审批，并生成授权记录。
4. **原料归属**：原料可以是公司采购，也可以是客户提供（客供料）。仓储按“货主”区分，客供料不计入公司存货金额，但必须管理数量、批次和损耗。
5. **计价模式**：支持加工费、产品销售、设备托管/使用费、维保服务费等一种或多种组合。
6. **设备费用**：若客户设备由公司使用并按合同需向客户支付设备使用费/托管费，系统在订单成本中记录“应付客户设备使用费”；若公司向客户收取设备维保/托管服务费，则形成应收。
7. **组织范围**：一期按“单公司、多部门、多仓库、多生产地点”设计；多法人、多工厂作为后续扩展。

### 1.4 系统边界

**本期包含：**

- 组织/员工/考勤、权限管理、客户与合同、设备管理、订单与生产执行、财务业务管理、流程审批、仓储、首页大屏及管理驾驶舱。
- 通用平台能力：编码规则、数据字典、附件、消息、待办、导入导出、打印、操作日志、报表。
- 与企微/钉钉、考勤机、电子发票、银行流水、IoT 设备网关等外部系统的接口预留。

**本期不包含或仅做接口：**

- 不替代法定会计总账、税务申报和合并报表；可按规则生成凭证并导出/对接金蝶、用友等财务软件。
- 不做完整 MES/SCADA 和设备远程控制；一期以手工报工和设备档案为主，IoT 数据采集作为二期。
- 不做复杂 APS 高级排程算法；一期提供可视化排产、产能校验和冲突提示。
- 不做完整 CRM 营销自动化（线索投放、自动化培育）；客户系统聚焦客户主数据、合同、跟进和 360 视图。
- 薪酬核算作为二期可选模块，一期先输出考勤结果和薪资接口数据。

### 1.5 设计原则

1. **主数据统一**：客户、物料、设备、仓库、员工、部门等主数据一处维护、全系统引用。
2. **单据驱动**：业务动作必须落成单据，库存和财务由单据驱动，不允许直接改数。
3. **状态机管理**：订单、工单、设备、审批、应收等都有明确状态和流转规则。
4. **权限最小化**：默认不可见，按需授权；敏感字段单独授权；权限变更留痕。
5. **职责分离**：申请人/审批人/执行人/复核人分离，财务付款与审批分离，系统管理员不默认拥有业务数据权。
6. **可配置优先**：审批流、角色权限、编码规则、字典、打印模板尽量配置化，减少硬编码。
7. **移动优先场景**：考勤、审批、报工、扫码出入库、设备点检优先支持手机/PDA。
8. **数据可追溯**：关键单据版本化，库存有台账，财务红冲不删除，审批意见不可篡改。

## 2. 总体架构与核心业务模型

### 2.1 功能架构

```text
┌──────────────────────────────────────────────────────────────┐
│ 门户层：PC 管理后台｜员工自助｜移动端/企微钉钉｜PDA｜大屏｜客户门户(可选) │
├──────────────────────────────────────────────────────────────┤
│ 业务层：员工考勤｜权限｜客户｜设备｜订单｜财务｜审批｜仓储｜首页大屏      │
├──────────────────────────────────────────────────────────────┤
│ 平台层：组织用户｜角色权限｜工作流｜消息待办｜文件｜编码｜报表｜集成｜日志 │
├──────────────────────────────────────────────────────────────┤
│ 数据层：主数据｜业务单据｜库存台账｜财务数据｜审批数据｜分析指标          │
└──────────────────────────────────────────────────────────────┘
```

### 2.2 核心实体关系

| 实体 | 关系 | 说明 |
|---|---|---|
| 客户 | 1:N 联系人、地址、合同、设备、订单、应收、开票、客户物资 | 客户是订单、设备、财务往来的核心归属 |
| 合同 | 1:N 订单 | 订单金额受合同剩余额度约束，特殊情况需审批 |
| 订单 | 1:N 订单行、工单、发货单、应收 | 订单行是生产和交付的最小业务单元 |
| 订单行 | 1:N 工单 | 一个订单行可拆分到多台客户设备生产 |
| 工单 | N:1 客户设备 | 工单必须绑定该客户名下设备；跨客户借用需授权 |
| 工单 | 1:N 领料、报工、质检、入库 | 生产过程全程追溯 |
| 设备 | N:1 客户 | 所有权归客户，支持托管/驻场 |
| 设备 | 1:N 维保计划、点检、维修工单、运行记录、排产任务 | 设备状态影响订单排产 |
| 仓库 | 1:N 库位、库存 | 库存按仓库+库位+物料+批次+货主+状态管理 |
| 库存 | N:1 物料、仓库、批次、货主 | 货主区分公司/客户，客供料单独核算 |
| 员工 | N:1 部门/岗位；1:N 考勤、申请、审批 | 组织架构决定数据权限 |
| 用户 | N:M 角色；N:M 部门；1:N 权限例外 | 最终权限=部门模板+角色+用户例外 |
| 审批实例 | 1:1 业务单据 | 审批状态与业务状态分离但联动 |

### 2.3 统一主数据

| 主数据 | 关键内容 | 维护部门 |
|---|---|---|
| 客户 | 企业信息、联系人、地址、信用、结算、开票信息 | 销售/财务审核 |
| 供应商（可选） | 外协、维修、物流、办公用品供应商 | 采购/财务 |
| 物料 | 原料、辅料、包材、备件、成品、半成品 | 仓储/生产 |
| 产品 | 可销售产品/加工服务、BOM、工艺路线、质量标准 | 生产/技术 |
| 设备 | 客户设备档案、位置、状态、维保参数 | 设备/生产 |
| 仓库/库位 | 仓库类型、库区、库位、货主规则 | 仓储 |
| 部门/岗位 | 组织树、负责人、编制、岗位职责 | 人事 |
| 员工 | 档案、任职、合同、资质、账号 | 人事 |
| 财务基础 | 科目映射、税率、结算方式、费用项目、银行账户 | 财务 |
| 通用字典 | 客户等级、行业、来源、物料分类、故障类型等 | 系统管理员 |

**规则：**

- 主数据采用“启用/停用”，被业务引用后禁止物理删除。
- 关键主数据（客户、设备、物料）变更需留版本或变更记录。
- 编码规则统一配置，如 `CUS-YYYYMM-0001`、`SO-YYYYMMDD-0001`、`EQ-客户编码-001`。
- 导入必须校验重复、必填、格式和关联关系，失败行可下载修正。

### 2.4 公共平台能力

| 能力 | 说明 |
|---|---|
| 编码规则 | 前缀+日期+流水，支持按组织/单据类型配置 |
| 自定义字段 | 客户、订单、设备等主单据可扩展字段，支持文本/数字/日期/下拉/附件 |
| 附件与影像 | 合同、验收单、发票、维修照片等，支持预览、水印、权限控制 |
| 消息中心 | 站内信、待办、企微/钉钉、短信/邮件，支持模板和免打扰 |
| 待办中心 | 审批、任务、预警、盘点、维保统一入口 |
| 导入导出 | Excel 模板导入、查询结果导出，导出需权限并记录日志 |
| 打印模板 | 订单、发货单、对账单、设备标签、库位标签等 |
| 操作日志 | 登录、查询敏感数据、增删改、审批、权限变更全记录 |
| 定时任务 | 合同到期、设备保养、库存预警、应收逾期、考勤异常提醒 |
| 集成接口 | OpenAPI/Webhook，支持企微/钉钉、考勤机、发票、银行、IoT |

## 3. 员工系统（组织、档案与考勤）

### 3.1 组织架构

**功能：**

- 公司 → 多级部门 → 岗位的组织树管理。
- 部门信息：名称、编码、上级部门、负责人、分管领导、编制人数、成本中心、生效日期、状态。
- 岗位信息：岗位名称、职级、所属部门、岗位职责、任职资格、默认角色。
- 支持员工“主部门 + 兼岗/兼部门”，数据权限以主部门为主、兼岗按授权扩展。
- 汇报关系：行政上级、业务上级、考勤负责人，供审批流和考勤组使用。
- 组织调整历史：部门合并、拆分、撤并时保留历史任职记录，不影响历史单据。

**规则：**

- 部门下有在职员工或未结业务时不能直接删除，只能停用。
- 部门负责人变更自动影响“部门负责人审批”节点，需有生效时间和审计。
- 组织树调整后，数据权限按“当前组织 + 历史快照”处理，避免历史数据突然不可见。

### 3.2 员工档案与全生命周期

**档案字段：**

| 分类 | 字段示例 | 权限 |
|---|---|---|
| 基本信息 | 工号、姓名、性别、出生日期、证件类型/号码、手机、邮箱、照片、紧急联系人 | 人事可编辑，其他人按通讯录范围查看 |
| 任职信息 | 部门、岗位、职级、员工类型、入职日期、试用期、转正日期、直属上级、工作地点、成本中心 | 人事/部门负责人 |
| 合同信息 | 合同编号、类型、期限、续签次数、到期提醒、附件 | 人事，财务可按需查看 |
| 资质证书 | 学历、职业资格、特种作业证、设备操作证、有效期 | 人事/设备主管 |
| 敏感信息 | 身份证、银行卡、社保、公积金、薪资 | 加密存储、字段脱敏、单独授权 |
| 账号信息 | 系统账号、角色、状态、最后登录 | 系统管理员 |

**生命周期：**

1. **入职**：入职申请 → 审批 → 建立档案 → 分配部门/岗位 → 开通账号 → 分配基础角色 → 绑定考勤组。
2. **试用期/转正**：转正提醒 → 转正申请 → 直属上级/人事审批 → 更新任职状态。
3. **调岗/调薪/兼岗**：调岗审批 → 生效日期 → 权限自动回收/新增 → 历史任职保留。
4. **离职**：离职申请 → 交接清单（客户、订单、设备、文件、资产、借款）→ 部门/人事/财务/IT 会签 → 账号禁用 → 考勤封存 → 薪资结算接口。
5. **返聘/再入职**：保留原档案编号或新建关联档案，避免历史考勤和薪资混淆。

**提醒：**

- 合同到期、试用期到期、证书到期、生日/入职周年（可关闭）。
- 离职未交接、账号长期未登录、权限异常。

### 3.3 考勤规则与班次

**考勤组：**

- 按部门、工作地点、岗位或指定人员建立考勤组。
- 每个考勤组配置：适用人员、班次、打卡方式、打卡地点/范围、节假日、异常判定、审批规则、封账日。
- 支持一个员工多个考勤组？一期建议一人一组，跨现场人员通过“外勤/出差”处理。

**班次类型：**

| 类型 | 说明 |
|---|---|
| 固定班 | 固定上下班时间，如 08:30–17:30 |
| 弹性班 | 允许一定时间范围内上下班，满足工时即可 |
| 排班制 | 按日/周/月排班，适合生产、设备值守 |
| 综合工时 | 按周期统计工时，支持淡旺季 |
| 跨天班 | 夜班跨自然日，考勤归集到上班日期 |

**配置项：**

- 上下班时间、休息时间、工作时长、迟到/早退宽限分钟数。
- 最小请假单位（小时/半天/天）、加班计算单位。
- 工作日、法定节假日、调休日、公司特殊工作日。
- 打卡方式：手机 GPS/WiFi/蓝牙、人脸识别、考勤机、外勤拍照。
- 打卡范围：地点坐标+半径、WiFi 名称、蓝牙设备、办公区人脸终端。
- 异常规则：缺卡、迟到、早退、旷工、重复打卡、跨地点打卡。
- 封账规则：每月固定日期封账，封账后调整需审批。

**排班：**

- 日历视图、批量排班、复制上周/上月、按班组排班。
- 换班申请：员工发起 → 对方确认 → 主管审批 → 更新排班。
- 节假日维护：国家法定节假日 + 公司特殊安排。
- 生产旺季可与订单排产联动，提示人员缺口（二期）。

### 3.4 打卡与异常处理

**打卡能力：**

- 手机打卡：定位、WiFi、蓝牙、拍照水印、设备绑定、模拟定位检测。
- 人脸打卡：考勤机/移动端人脸，活体检测（按硬件能力）。
- 考勤机打卡：通过接口同步原始记录，支持多家品牌适配。
- 外勤打卡：关联客户、拜访目的、照片、备注；可自动生成客户跟进记录。
- 出差打卡：按出差行程自动豁免或记录，支持多城市。
- 补卡：限定次数/时间范围，需审批，标注原因。
- 代打卡防控：设备变更、异常定位、频繁补卡、集中打卡预警。

**异常处理流程：**

```text
考勤日结 → 生成异常（迟到/早退/缺卡/旷工）
   → 员工收到提醒 → 提交补卡/请假/出差说明
   → 直属上级审批 → 人事复核 → 考勤结果更新
```

**规则：**

- 原始打卡记录不可修改，只能新增/冲正并留痕。
- 考勤异常必须在封账前处理；封账后调整走“考勤调整审批”。
- 法定节假日、休息日加班按不同倍率计入，具体倍率由公司制度配置。
- 定位/人脸数据仅用于考勤，遵循最小化采集和员工告知同意。

### 3.5 请假、加班、出差与调休

| 业务 | 关键功能 | 规则 |
|---|---|---|
| 请假 | 类型、事由、起止时间、时长、附件、审批、销假 | 年假/调休扣减额度；病假可要求证明；最小单位可配置 |
| 加班 | 加班申请、实际打卡、加班确认、调休/加班费 | 支持事前申请/事后补录；按工作日/休息日/节假日计算 |
| 出差 | 行程、目的地、客户、交通/住宿、同行人、审批 | 出差期间考勤自动关联；可生成费用报销草稿 |
| 外勤 | 客户拜访、现场服务、临时外出 | 打卡关联客户/设备/工单；形成跟进或服务记录 |
| 调休 | 加班转调休、调休余额、使用期限 | 到期提醒，过期规则可配置 |
| 补卡 | 日期、时段、原因、证明 | 次数限制，月末集中补卡预警 |

**审批联动：**

- 请假/加班/出差/补卡均通过统一审批引擎，审批通过后回写考勤。
- 审批撤销/驳回时回滚考勤占用，避免额度重复扣减。
- 审批中的申请在考勤报表中单独标识“待审批”，不直接算异常。

### 3.6 考勤统计与薪酬接口

**统计报表：**

- 个人考勤明细、月度汇总、异常明细、迟到早退统计。
- 部门出勤率、请假率、加班时长、外勤天数、出差天数。
- 排班执行率、换班记录、未处理异常。
- 按成本中心/项目/客户统计人工工时（为订单成本提供数据）。
- 考勤封账报表、薪资接口表。

**薪酬接口：**

- 输出字段：员工、部门、应出勤天数、实际出勤、请假类型/时长、加班类型/时长、迟到早退次数、旷工、补卡、出差、外勤。
- 支持导出 Excel 或 API 推送；薪资计算规则不在一期考勤模块内硬编码。
- 薪资/银行卡等敏感数据不在考勤报表中展示。

### 3.7 员工自助与移动端

**员工端：**

- 我的考勤日历、打卡、补卡、请假、加班、出差、外勤申请。
- 我的审批、待办、消息、个人档案、通讯录。
- 合同/证书到期提醒、工资条（二期）。
- 扫码查看设备/工单（按权限）。

**主管端：**

- 团队今日出勤、异常、请假/加班待办。
- 排班、换班审批、考勤异常处理。
- 团队考勤月报、工时成本。

**人事端：**

- 考勤组、班次、排班、节假日、封账。
- 异常批量处理、补卡审核、考勤调整。
- 员工档案、合同、证书、离职交接。

### 3.8 关键权限与验收要点

**权限：**

- 员工：仅本人考勤、申请、档案。
- 直属上级：本团队考勤与审批。
- 部门负责人：本部门及下级（按配置）。
- 人事：全公司考勤规则与档案，敏感字段单独授权。
- 财务：仅薪酬接口/汇总，不查看人脸、定位原图。

**验收要点：**

- 固定班、排班制、跨天夜班、弹性班均能正确计算。
- 迟到/早退/缺卡/旷工规则可配置，异常可申诉并审批。
- 请假额度扣减、撤销回滚、加班转调休准确。
- 封账后数据不可直接修改，调整有审批和日志。
- 手机定位打卡有防作弊措施，隐私授权完整。
- 考勤结果可按部门/个人导出，并能生成薪资接口数据。

## 4. 权限管理（部门可后台手动配置）

### 4.1 权限模型

采用 **RBAC + 组织数据权限 + 字段权限 + 操作权限 + 审批权限** 的组合模型：

```text
用户最终权限 =
  部门默认权限模板
  ∪ 岗位/角色权限
  ∪ 用户额外授权
  − 显式禁止
  并受“部门数据权限上限”约束
```

**说明：**

- **功能权限**取并集，显式禁止优先。
- **数据权限**在角色配置范围内取并集，但不得超过部门允许的最大数据范围，防止越权。
- **字段权限**按“可见/可编辑/脱敏/不可见”四级控制，敏感字段单独授权。
- **审批权限**与业务操作权限分离：能看订单不等于能审批订单。
- **职责分离**：系统管理员负责配置，不默认拥有业务数据；财务付款审批与执行分离。

### 4.2 权限对象

| 对象 | 说明 |
|---|---|
| 用户 | 员工账号，支持一人一号、禁用、锁定、SSO |
| 角色 | 权限集合，如销售、生产主管、仓管、会计、出纳、人事 |
| 部门 | 权限继承和分配的基本单位，支持多级 |
| 岗位 | 可绑定默认角色，员工调岗自动调整 |
| 菜单 | 一级/二级菜单、页面访问 |
| 操作/按钮 | 新增、编辑、删除、审核、导出、打印、红冲等 |
| API | 后端接口级权限，防止绕过前端 |
| 数据资源 | 客户、订单、设备、仓库、财务单据、员工等 |
| 字段 | 金额、成本、毛利、折扣、银行账号、身份证、手机号等 |
| 审批节点 | 特定流程/金额/部门的审批资格 |

**权限编码规范：**

```text
模块:资源:动作
order:order:create
order:order:approve
finance:receivable:view_amount
warehouse:inventory:adjust
system:permission:grant
```

### 4.3 数据权限范围

| 范围 | 说明 | 典型场景 |
|---|---|---|
| 全部数据 | 全公司 | 总经理、财务总监 |
| 本部门及下级 | 组织树向下 | 部门负责人 |
| 本部门 | 仅本部门 | 部门主管 |
| 本部门及指定部门 | 手动勾选协作部门 | 跨部门项目 |
| 仅本人 | 本人创建/负责 | 销售、普通员工 |
| 本人及下属 | 汇报关系向下 | 销售主管 |
| 自定义 | 指定人员/客户/仓库/设备/项目 | 专项小组 |
| 无权限 | 不可见 | 默认 |

**数据权限示例：**

- 销售：只能看自己负责的客户/订单；可看客户设备只读；不能看成本、毛利。
- 销售主管：本部门及下级销售数据；可审批折扣。
- 生产主管：所有生产订单、工单、设备状态；不能看订单价格和客户回款。
- 设备工程师：分配给自己的客户设备及维保工单；不能看财务金额。
- 仓管：指定仓库的库存和出入库；不能看采购价格/库存金额（可配置）。
- 财务：全部财务单据；客户/订单只读；成本、发票、银行账户可见。
- 出纳：资金账户、收付款执行；不能修改应收/应付单据。
- 人事：员工档案、考勤、组织；不能看业务订单。
- 系统管理员：系统配置、权限、日志；默认不进入业务数据。

### 4.4 部门权限后台配置流程

**配置入口：权限中心 → 部门权限配置**

1. **选择部门**：左侧组织树，显示部门负责人、人数、当前权限模板。
2. **选择权限模板**：从内置模板（销售部、生产部、设备部、仓储部、财务部、人事部、管理层）复制，或自定义。
3. **配置菜单与操作**：勾选模块、页面、按钮（新增/编辑/导出/审批等）。
4. **配置数据范围**：本部门/本部门及下级/指定部门/全部/仅本人；设置金额上限、客户范围、仓库范围。
5. **配置字段权限**：金额、成本、毛利、折扣、银行账号、身份证、手机号等设置为可见/脱敏/隐藏/可编辑。
6. **配置岗位差异**：岗位继承部门模板，可单独覆盖；如销售专员 vs 销售主管。
7. **配置用户例外**：对个别员工增加或禁止权限，必须填写原因和有效期。
8. **预览生效结果**：选择某个用户，模拟其最终菜单、按钮、数据范围、字段可见性。
9. **提交审批**：权限变更可按公司要求走审批（部门负责人 + 系统管理员/信息安全）。
10. **生效与审计**：立即生效或定时生效；记录变更前后差异、操作人、原因；支持版本回滚。

**部门配置规则：**

- 子部门默认继承父部门模板，可覆盖；父部门可锁定关键权限，禁止下级扩大。
- 部门负责人自动获得本部门审批/查看权限，可在模板中关闭。
- 员工调岗：新部门权限生效，旧部门权限自动回收；可配置过渡期。
- 离职：账号立即禁用，权限保留审计快照，不保留访问权。
- 跨部门协作：通过“项目/订单/客户团队成员”授权，设置只读/可编辑和有效期，到期自动回收。
- 权限变更不影响历史审批责任；历史单据仍显示原审批人。
- 权限缓存需支持快速刷新，避免“改了权限不生效”。

### 4.5 字段级与敏感数据权限

| 数据 | 默认可见 | 脱敏/限制 | 额外授权 |
|---|---|---|---|
| 客户联系方式 | 归属销售、客服 | 手机号中间四位脱敏 | 导出需审批 |
| 订单金额/折扣 | 销售、财务 | 成本、毛利默认隐藏 | 销售总监/总经理 |
| 设备原值/客户资产值 | 设备主管、财务 | 普通员工不可见 | 按客户授权 |
| 银行账号/开票信息 | 财务 | 账号脱敏 | 出纳/会计 |
| 员工身份证/银行卡 | 人事、财务 | 默认脱敏 | 单独授权+日志 |
| 考勤定位/人脸 | 人事、本人 | 不向业务主管展示原图 | 合规审批 |
| 库存成本 | 财务、仓储主管 | 仓管员仅数量 | 按仓库授权 |

**敏感操作：**

- 批量导出客户/员工/财务数据需二次确认，记录导出人、时间、条数、用途。
- 修改权限、红冲凭证、调整库存、删除附件需填写原因。
- 管理员登录建议启用 MFA；高权限账号建议 IP 白名单。

### 4.6 临时授权、代理与权限申请

- **临时授权**：因项目/出差/紧急任务申请临时角色或数据权限，必须设置起止时间，到期自动回收。
- **审批代理**：员工请假时可指定代理人处理审批，仅转移审批待办，不转移数据权限；代理记录可审计。
- **权限申请**：员工发起 → 部门负责人 → 系统管理员/信息安全 → 生效；申请单关联权限项和期限。
- **定期复核**：每季度/每半年生成权限复核清单，部门负责人确认；长期未登录账号自动提醒/禁用。
- **离职/调岗联动**：人事流程触发权限回收，IT/系统管理员确认。

### 4.7 权限审计与安全

- 权限变更日志：谁、何时、给谁、增加了什么、删除了什么、原因、审批单号。
- 登录日志：IP、设备、时间、失败原因；异常登录告警。
- 数据访问日志：查看/导出敏感数据、查看他人薪资/客户。
- 权限快照：支持按时间点还原用户权限，便于审计。
- 职责分离检查：超级管理员数量、付款审批人与执行人是否同一人、仓库调整与审批是否同一人。
- 定期输出“权限风险报告”：长期未用权限、越权尝试、离职未回收、角色过多。

### 4.9 验收要点

- 部门权限模板可复制、继承、覆盖、锁定，配置后能预览最终效果。
- 用户菜单、按钮、API、数据范围、字段脱敏五层一致，不能通过直接调用接口越权。
- 调岗/离职/临时授权到期能自动调整权限。
- 权限变更全量留痕，可按人/时间/操作人查询。
- 权限矩阵能导出，支持季度复核。

## 5. 客户系统

### 5.1 客户主数据

**基础信息：**

- 客户编码、客户名称、简称、客户类型（企业/个人）、统一社会信用代码。
- 行业、区域、规模、客户来源、客户等级（A/B/C/D）、标签。
- 客户状态：潜在、合作中、暂停合作、流失、黑名单。
- 归属销售、归属部门、协作人、保护期。
- 首次合作日期、最近成交日期、最近跟进日期。

**商务与财务信息：**

- 结算方式（现结/月结/账期/预付款）、信用额度、信用天数、已用额度、可用额度。
- 开票信息：抬头、税号、地址、电话、开户行、账号。
- 默认税率、币种、价格体系/折扣政策。
- 合同模板、对账周期、发票类型。

**联系人：**

- 姓名、职务、角色（决策人/采购/财务/技术/收货）、手机、邮箱、微信、备注。
- 主联系人标记；同一客户多联系人；联系人变更历史。
- 联系人离职/失效标记，避免继续跟进。

**地址：**

- 注册地址、开票地址、收货地址、设备安装地址。
- 联系人、电话、经纬度、默认地址标记。
- 支持多地址，订单/发货/设备分别引用。

**附件与资质：**

- 营业执照、开户许可证、一般纳税人证明、质量协议、保密协议、合同扫描件。
- 客户现场照片、设备照片、验收单。

**关系与重复校验：**

- 母公司/子公司/关联客户。
- 按名称、信用代码、手机号、地址查重；合并客户需审批并保留旧编号映射。
- 客户名称变更、信用额度调整、归属变更需审批。

### 5.2 客户归属与公海

- **私海**：销售负责的客户，保护期内其他销售不可重复跟进。
- **公海**：长期未跟进、主动释放、离职回收的客户，可被认领。
- **规则**：多少天未跟进自动掉公海、每人最多持有多少客户、认领上限、保护期天数。
- **防撞单**：新建客户/商机时查重；冲突时由销售主管裁定。
- **离职交接**：客户、订单、设备、应收一并交接，交接清单审批。
- **客户等级**：按成交额、回款、毛利、战略价值等自动/手动评级，影响审批层级和服务策略。

### 5.3 合同与价格协议

**合同类型：**

- 销售合同、框架合同、加工服务合同、设备托管合同、设备维保合同、保密协议。

**合同信息：**

- 合同编号、客户、类型、签订日期、生效/到期日期、合同金额、税率、币种。
- 付款条款（预付款/进度款/尾款/账期）、交付条款、验收标准、质保期、违约责任。
- 合同行：产品/服务、规格、数量、单价、金额、交付节点。
- 附件、电子签章、审批记录、变更记录。
- 合同执行视图：已下单金额、已发货、已开票、已收款、剩余额度。

**规则：**

- 订单关联合同，订单金额不得超过合同剩余额度；超额度需审批。
- 合同到期/续签提醒；终止需审批并检查未执行订单。
- 价格协议：按客户/产品/有效期维护协议价；订单价格低于协议价或最低价需审批。
- 合同变更保留版本，已执行部分不回溯修改。

### 5.4 客户 360 视图

一个页面聚合客户全貌：

- **基本信息**：等级、归属、信用、结算、标签、风险提示。
- **联系人/地址**：主联系人、收货/安装地址。
- **合同**：有效合同、金额、剩余额度、到期提醒。
- **设备**：客户名下设备、位置、状态、利用率、维保计划、故障。
- **订单**：历史订单、在制订单、交期、生产进度、发货记录。
- **财务**：应收余额、逾期账龄、开票、回款、信用占用。
- **库存**：客户客供料、客户成品、在库数量、对账差异。
- **服务**：维修工单、投诉、售后记录、SLA。
- **跟进**：拜访/电话/邮件记录、下次行动、附件。
- **审批**：与该客户相关的进行中审批。
- **风险**：逾期、信用超限、设备停机、投诉、合同到期。

### 5.5 客户跟进与服务

- 跟进记录：方式（拜访/电话/微信/邮件）、时间、联系人、内容、下次计划、附件。
- 外勤拜访可关联考勤打卡和定位，自动生成跟进记录。
- 商机/报价（可选轻量）：商机阶段、预计金额、赢单/输单原因；报价单可转订单。
- 客户投诉/服务请求：生成工单，关联设备/订单，跟踪响应和关闭。
- 客户满意度回访（可选）。
- 提醒：长期未跟进、合同到期、信用超限、设备保养到期、应收逾期。

### 5.6 客户变更、冻结与黑名单

- 客户名称、信用额度、结算方式、归属销售、开票信息变更需审批。
- 信用超限/严重逾期可冻结：冻结后禁止新订单或禁止发货，需特批解冻。
- 黑名单：恶意欠款、欺诈、严重违约；黑名单客户下单需总经理审批。
- 客户合并：保留主客户，关联历史订单/设备/财务，旧编号可查询。
- 客户注销：检查未结订单、应收、设备、库存，完成后停用。

### 5.7 客户报表

- 新增客户数、活跃客户数、流失客户数、客户留存率。
- 客户成交排行、贡献毛利排行、应收逾期排行、信用占用排行。
- 客户行业/区域/来源分布。
- 客户设备数量、设备利用率、维保成本。
- 客户订单频率、平均客单价、复购率。
- 销售跟进排行、拜访次数、转化率（如有商机）。

### 5.8 客户门户（二期可选）

- 客户登录查看：订单进度、生产状态、设备状态、发货记录、对账单、发票、服务请求。
- 严格数据隔离：只能看自己的数据；手机号/验证码登录；操作留痕。
- 客户确认对账单、签收、提交服务请求。
- 与内部权限体系隔离，客户账号不进入员工组织。

### 5.9 关键规则与验收要点

- 客户必须唯一归属，跨部门协作通过团队成员授权。
- 订单、设备、合同、应收必须能追溯到客户。
- 客户 360 页面数据权限与各模块一致，不能因聚合页面泄露成本/其他客户数据。
- 客户合并/归属变更后，历史单据归属可追溯。
- 信用额度、账期、冻结状态能实时影响订单和发货。

## 6. 设备管理（客户设备）

### 6.1 管理定位

设备模块管理的是 **客户拥有的生产设备/检测设备/辅助设备/模具治具**，公司可能是：

- 设备托管方：设备放在公司场地，由公司使用/保管。
- 设备使用方：公司在客户现场使用客户设备生产。
- 设备服务方：公司为客户提供安装、维保、维修、操作服务。

因此设备档案必须同时记录 **所有权、保管责任、使用责任、位置、合同依据**，而不是简单等同于公司固定资产。

### 6.2 设备档案

| 分类 | 字段 |
|---|---|
| 基本信息 | 公司设备编号、客户设备编号、设备名称、类别、型号、序列号、制造商、出厂日期、启用日期 |
| 归属信息 | 所有权（客户）、所属客户、托管/使用合同、客户联系人 |
| 位置信息 | 地点类型（公司场地/客户现场/第三方）、地址、车间/产线/工位、经纬度、责任部门、责任人 |
| 状态信息 | 待进场、安装调试、验收中、在用、停机、维修中、封存、待退场、已退场 |
| 技术参数 | 规格、产能、精度、功率、工艺范围、支持的工序、操作要求 |
| 商务信息 | 设备原值（客户资产，权限控制）、保修期、维保合同、收费标准、保险信息 |
| 文档 | 说明书、合格证、图纸、验收单、维保记录、照片、二维码 |
| 人员 | 设备负责人、操作员、维保人、客户对接人 |
| 提醒 | 保修到期、保养到期、点检逾期、证书到期 |

**规则：**

- 设备编号全公司唯一；客户设备编号可重复，需按客户隔离。
- 设备必须归属客户，不允许无客户设备。
- 所有权变更只能由客户发起并审批，保留历史。
- 设备停用/退场前检查未完成工单、维保、备件、客户物资。
- 设备二维码：扫码查看档案、点检、报修、报工（按权限）。

### 6.3 设备进场、安装、移机与退场

**进场流程：**

```text
客户/销售发起设备进场申请
 → 设备部审核
 → 登记设备信息、配件、外观、照片
 → 客户签字确认
 → 安装调试
 → 验收（精度/产能/安全）
 → 状态改为“在用”
```

**移机：**

- 移机申请（原因、原位置、新位置、时间、责任人）。
- 停用原设备 → 拆卸/运输 → 安装调试 → 验收 → 更新位置。
- 移机期间的订单影响提示，必要时触发排产调整。

**退场：**

- 退场申请 → 检查未结工单/维保/备件/客户物资 → 设备状态确认 → 客户验收 → 放行条 → 状态“已退场”。
- 损坏/缺失责任认定，关联赔偿/维修费用。
- 退场后档案保留，不可删除。

### 6.4 设备运行管理

- 设备状态看板：按客户、地点、产线、状态筛选。
- 启停记录：开机/停机时间、操作员、班次、停机原因（故障、待料、待单、保养、停电）。
- 运行时长、产量、良品/不良品、OEE（设备综合效率）。
- 手工报工：操作员在手机/PDA 选择工单、设备、数量、开始/结束时间。
- IoT 接入（二期）：PLC/网关采集运行、产量、报警、能耗；与手工报工并存，标注数据来源。
- 设备日历：班次、保养计划、停机计划、订单占用。
- 异常提醒：长时间停机、空转、产量异常、保养逾期、保修到期。
- 设备利用率、故障率、MTBF、MTTR 报表。

### 6.5 点检、保养与维修

**点检：**

- 点检模板：日常/周/月，检查项、标准、是否拍照、异常处理。
- 手机扫码点检，记录结果、照片、位置、时间。
- 异常项自动转维修工单或异常单。
- 点检逾期提醒，未点检设备清单。

**保养：**

- 保养计划：按日历周期或运行时长触发。
- 保养内容、备件、责任人、预计工时。
- 自动生成保养工单，完成后记录实际工时、备件、费用、下次保养日期。
- 保养计划与订单排产联动，提前锁定停机窗口。

**维修：**

```text
报修（客户/操作员/点检异常）
 → 设备主管派工
 → 工程师接单/到场
 → 故障诊断、维修、更换备件
 → 试机/验收
 → 客户签字（如收费/客户设备）
 → 关闭工单
```

- 故障类型、现象、原因、处理方案、停机时长、响应/修复 SLA。
- 备件消耗：公司备件/客户备件，关联库存。
- 外委维修：供应商、报价、审批、费用。
- 维修费用：免费保修/合同内/按次收费，形成应收或成本。
- 知识库：故障代码、解决方案、历史案例。
- 客户设备维修需客户确认，避免责任纠纷。

### 6.6 设备产能与订单排产

- 每台设备维护可用日历、班次、产能（件/小时或工序节拍）、换型时间、良率。
- 订单排产时只能选择该客户名下设备；显示设备未来占用、保养、停机。
- 一台设备同一时段原则上只能排一个工单；多工位/多模腔设备可配置并行能力。
- 跨客户借用设备：需“设备借用授权”审批（双方销售负责人、生产负责人、总经理），授权记录有效期和使用范围。
- 设备故障/保养冲突时，系统提示受影响订单，建议改排或调整交期。
- 设备运行数据回写工单进度，支持客户查询订单进度（可选）。
- 设备使用费/托管费按运行时长、产量或合同约定计算，传递财务。

### 6.7 备件与工具

- 备件档案：物料编码、适用设备、库存、安全库存、供应商。
- 备件领用关联维修工单，区分公司承担/客户承担。
- 客户提供的备件单独建账，不纳入公司存货金额。
- 工具/治具借出归还，逾期提醒。
- 备件库存预警、呆滞分析。

### 6.8 设备成本与结算

- 设备维保成本：人工、备件、外委、差旅、停机损失（可选）。
- 客户设备使用费/托管费：应付客户或应收客户，按合同规则计算。
- 维保服务费：按合同/工单收费，形成应收。
- 设备成本按客户/设备/订单归集，支持毛利分析。
- 设备保险、年检、校准费用记录。

### 6.9 设备报表

- 客户设备台账：数量、位置、状态、原值（权限）、保修。
- 设备利用率、OEE、故障率、MTBF、MTTR、停机时长。
- 保养计划完成率、点检及时率、维修 SLA。
- 维保成本、备件消耗、外委费用。
- 设备产出/订单贡献、客户设备投资回报（可选）。
- 即将到期：保修、保养、点检、证书、合同。

### 6.10 关键规则与验收要点

- 设备必须归属客户，订单工单必须绑定同客户设备；跨客户使用有授权和审批。
- 设备状态变化、移机、退场、维修全程留痕。
- 设备停机/保养能影响排产并提示订单风险。
- 客户设备价值、维修成本等敏感字段按权限隔离。
- 扫码可完成点检、报修、报工，移动端可用。
- 设备台账与客户 360、订单、仓储备件、财务应收/应付数据一致。

## 7. 订单系统

### 7.1 订单类型与来源

| 类型 | 说明 |
|---|---|
| 加工生产订单 | 主要类型，使用客户设备加工客户产品，按加工费结算 |
| 产品销售订单 | 公司销售自产/外购产品，可能使用客户设备或公司设备 |
| 设备服务订单 | 设备安装、维保、维修、移机、托管服务 |
| 样品/试制订单 | 小批量试产，单独核算成本 |
| 返工/补货订单 | 质量返工、客户补货，关联原订单 |

**来源：** 手工创建、合同生成、客户门户、Excel 导入、历史订单复制、报价单转订单。

**基本规则：**

- 订单必须归属一个客户，客户状态、信用、结算方式校验。
- 订单可关联合同；无合同订单需审批（按金额/客户等级）。
- 订单行可选择产品/加工服务，维护数量、价格、交期、质量标准。
- 订单可由多个订单行组成，每个订单行可拆分到多台客户设备生产。

### 7.2 订单结构

**订单头：**

- 订单号、订单类型、客户、合同、下单日期、客户 PO 号。
- 销售负责人、归属部门、优先级（普通/急单/特急）。
- 要求交期、承诺交期、发货地址、收货联系人。
- 结算方式、账期、信用占用、币种、税率。
- 订单总金额、折扣、税额、含税/未税金额。
- 订单状态、审批状态、生产状态、发货状态、收款状态、开票状态。
- 备注、附件（客户订单、图纸、质量协议、样品照片）。

**订单行：**

- 行号、产品/服务、规格型号、单位、数量、单价、折扣、税率、金额。
- 交付日期、交付数量、已生产、已入库、已发货、未发货。
- BOM/配方、工艺路线、质量要求、包装要求。
- 是否客供料、客供料清单、损耗率。
- 指定客户设备（可多选/拆分工单）。
- 客户 PO 行号、项目号。

**生产工单：**

- 工单号、订单行、数量、客户设备、工序、计划开始/结束、实际开始/结束。
- 操作员/班组、优先级、状态（待排产/已排产/待生产/生产中/暂停/待质检/已完成/已取消）。
- 实际产出、良品、不良品、报废、返工。
- 领料记录、报工记录、质检记录、入库记录。
- 设备使用时长/产量（用于计费）。

### 7.3 订单创建与校验

创建/提交订单时自动校验：

1. **客户校验**：客户存在、状态正常、未冻结/黑名单（黑名单需特批）。
2. **信用校验**：信用额度、账期、逾期金额；超限时阻断或走信用特批。
3. **合同校验**：合同有效、剩余额度足够；无合同/超合同需审批。
4. **价格校验**：协议价/最低价/折扣权限；低于底价需审批。
5. **设备归属校验**：订单行指定设备必须属于该客户；否则阻断并提示走借用审批。
6. **设备可用性校验**：设备状态、保养计划、已有排产冲突；冲突时提示可选交期。
7. **物料校验**：BOM 物料库存、客供料到位情况、采购在途；缺料提示。
8. **产能校验**：按设备产能和交期估算是否可完成；超负荷提示。
9. **重复校验**：客户 PO 号、产品+交期+数量重复提醒。
10. **审批校验**：金额、折扣、信用、非标条款、急单触发对应审批流。

### 7.4 订单审批与变更

**审批场景：**

- 订单确认（新建/大额/新客户）。
- 价格折扣低于权限、低于最低价。
- 信用超限、账期超标准。
- 无合同订单、合同超额度。
- 急单/插单影响已排产订单。
- 订单变更、取消、超量发货。
- 跨客户设备借用。

**订单变更：**

- 可变更内容：数量、交期、价格、规格、设备、收货地址、付款条件。
- 变更必须生成新版本，记录变更原因、影响分析（物料、排产、成本、应收）。
- 已投产订单变更需生产、仓储、财务会签；必要时暂停工单。
- 变更审批通过后，系统自动调整工单、领料、排产、应收计划，并通知相关方。
- 变更历史可追溯，打印/对账使用最新版本，历史版本可查。

**取消/关闭：**

- 未投产订单可申请取消；已投产需生产/仓储/财务确认，处理退料、在制品、已发生费用。
- 订单关闭条件：所有订单行生产完成、发货完成、退货处理完毕；财务应收可单独挂账。
- 关闭后原则上不可修改；重新打开需审批并记录原因。

### 7.5 订单状态机

```text
草稿
 → 待审批
 → 已确认
 → 待排产
 → 已排产
 → 生产中
 → 待质检
 → 待入库
 → 待发货
 → 部分发货
 → 已完成
 → 已关闭

异常分支：驳回 → 草稿；取消 → 已取消；暂停 → 生产中/已排产
```

**独立状态：**

- 审批状态：未提交、审批中、通过、驳回、撤回。
- 生产状态：未开始、部分完成、已完成、暂停、异常。
- 发货状态：未发货、部分发货、已发货、已签收。
- 收款状态：未收款、部分收款、已收款、逾期。
- 开票状态：未开票、部分开票、已开票、红冲。

**规则：**

- 只有“已确认”订单可排产。
- 未质检/未入库不能发货（特殊情况需审批）。
- 发货前校验信用/逾期；超期客户需特批。
- 订单完成以交付+签收为准，财务关闭独立控制。
- 状态变更必须通过业务动作触发，不允许直接改状态字段。

### 7.6 生产排产（绑定客户设备）

**排产流程：**

```text
订单确认
 → 生成待排产工单（按订单行/数量/设备拆分）
 → 选择客户名下设备
 → 检查设备日历、保养、停机、已有任务
 → 安排计划开始/结束、班组、优先级
 → 物料齐套检查
 → 发布排产计划
 → 通知生产/设备/仓储
```

**排产视图：**

- 设备甘特图：横轴时间、纵轴设备，显示工单、保养、停机。
- 订单视角：订单交期、已排/未排数量、预计完成时间。
- 负荷视图：设备/班组/工序未来负荷，超负荷红色提示。
- 冲突检测：同一设备时间重叠、保养冲突、操作员资质不符、物料未齐套。
- 拖拽调整（二期）：调整后记录原因，通知相关方。
- 冻结窗口：未来 N 小时内变更需审批，避免频繁扰动生产。

**排产约束：**

- 设备必须属于订单客户（或已授权借用）。
- 设备状态可用、无保养/维修冲突。
- 操作员具备设备操作资质（证书有效期）。
- 物料齐套或客供料已到位。
- 交期优先级、急单规则、客户等级。
- 换型时间、清洗时间、最小生产批量。

**异常重排：**

- 设备故障、保养超时、物料短缺、质量异常、急单插入。
- 系统提示受影响订单和交期风险，给出可替代设备/时段建议。
- 重排记录原因，通知销售/客户（可选）。
- 因客户原因导致的停工/待料，记录并可计费（按合同）。

### 7.7 生产执行与报工

**执行流程：**

```text
工单下达 → 领料（公司料/客供料）→ 生产 → 报工
 → 首件/巡检/终检 → 成品入库 → 工单关闭
```

**领料：**

- 按 BOM 和工单数量生成领料单；支持批次指定、替代料审批。
- 公司物料出库计入订单成本；客供料出库只记数量，不计金额。
- 超领需审批；余料退库；损耗率分析。
- 缺料时可部分领料/分批生产，工单状态标注“待料”。

**报工：**

- 操作员手机/PDA/终端选择工单、设备、工序，录入开始/结束、产量、良品、不良、报废、停机原因。
- 支持按班次汇总、批量报工、补报（需审批）。
- 记录操作员、设备、班次、工时，作为人工成本和设备使用费依据。
- 报工后自动更新订单进度、设备产量、库存待入库数量。

**质检：**

- 首件检验、过程巡检、成品检验；可配置抽检/全检。
- 检验项、标准、结果、不良代码、照片、检验员。
- 不合格处理：返工、返修、让步接收、报废；需审批。
- 质量记录关联订单、工单、设备、批次、操作员，支持追溯。
- 客诉/退货可回溯到生产批次和设备。

**异常管理：**

- 缺料、设备故障、质量异常、人员不足、工艺异常。
- 异常上报 → 责任部门处理 → 关闭；影响交期时通知销售/客户。
- 停机/待料时长记录，用于设备效率和订单成本。

### 7.8 发货、签收与退货

**发货：**

- 成品入库后生成发货申请，选择订单行、数量、批次/序列号。
- 发货前校验：信用、逾期、质检合格、库存可用。
- 出库单/送货单/装箱单/物流单，打印或推送客户。
- 支持部分发货、多次发货、合并发货。
- 物流信息、运费、保险、承运商记录。
- 客户签收：电子签收/回单上传/扫码确认；签收后订单交付状态更新。

**退货/返工：**

- 客户退货申请（原因、数量、批次、照片）→ 质量/销售/财务审批。
- 退货入库至待检仓 → 质检 → 返工/报废/退款/换货。
- 关联原订单、原发货单、应收/发票；必要时开红字发票。
- 返工工单单独核算成本；责任归属（公司/客户/供应商）。

### 7.9 订单成本与毛利

**成本构成：**

- 公司材料成本（按领料批次/移动加权平均）。
- 客供料：数量计入，金额为 0（或按客户要求记录参考值）。
- 人工成本：报工工时 × 工时费率，或计件工资。
- 设备使用费：应付客户的设备托管/使用费（按合同/时长/产量）。
- 能耗、辅料、包材、外协、运费、质量损失。
- 设备维修/停机损失（可选）。

**核算方式：**

- 订单确认时形成预估成本；生产过程中归集实际成本；完工后结算。
- 按订单/订单行/工单/客户/产品/设备多维分析。
- 实际与预估差异分析：材料、人工、设备、损耗、返工。
- 毛利率 =（订单收入 − 订单成本）/ 订单收入。
- 成本数据仅财务/管理层可见，销售默认只看收入不看成本。

### 7.10 订单报表

- 订单台账、订单进度、交期预警、逾期订单。
- 订单金额/数量趋势、客户订单排行、产品销售排行。
- 准时交付率、订单周期、在制订单、未发货订单。
- 急单占比、变更/取消率、返工率、客诉率。
- 订单毛利、客户毛利、产品毛利、设备产出。
- 销售业绩、回款关联、信用占用。

### 7.11 关键规则与验收要点

- 订单必须归属客户；工单必须绑定同客户设备，跨客户使用有授权审批。
- 订单金额、折扣、信用、合同额度校验生效，越权无法提交。
- 订单变更版本化，能追踪对生产、库存、财务的影响。
- 排产能检测设备冲突、保养冲突、缺料、资质不符。
- 报工/质检/入库/发货数据贯通，订单进度实时准确。
- 订单成本能归集材料、人工、设备使用费，毛利可计算。
- 订单状态与审批、生产、发货、收款状态独立且联动。

## 8. 财务系统

### 8.1 定位与边界

财务模块定位为 **业务财务一体化**：

- 负责应收、应付、收款、付款、发票、费用报销、资金、订单成本、对账、结账。
- 业务单据自动生成财务数据，财务复核确认，避免重复录入。
- 不替代法定会计总账/税务申报；通过科目映射生成凭证，导出/对接金蝶、用友等。
- 所有财务单据不物理删除，错误用红冲/反审核处理。

**角色分离：**

- 业务经办：发起付款/报销/开票申请。
- 财务主管：审核政策、信用、费用、付款。
- 会计：应收应付、发票、成本、凭证。
- 出纳：资金收付执行、银行对账。
- 审批人：按金额/权限审批。
- 系统管理员：不默认拥有财务数据权限。

### 8.2 应收账款

**应收来源：**

- 订单/合同收款计划（预付款、进度款、尾款）。
- 设备维保/维修服务费。
- 设备托管/使用费（如公司向客户收取）。
- 其他应收（赔偿、租金、利息）。

**功能：**

- 应收单：客户、来源单据、金额、税率、到期日、结算方式、负责人。
- 收款计划：按合同节点/订单/月结生成，支持分期。
- 收款登记：收款日期、金额、方式（银行/现金/承兑/微信/支付宝）、账号、流水号、附件。
- 收款核销：按应收单/发票核销，支持部分核销、多对多核销、预收款转应收。
- 预收款：先收款后开票/发货，余额管理。
- 开票：开票申请 → 审批 → 开票（电子发票接口/手工登记）→ 发票号、税额、抬头。
- 红字发票/发票作废：关联原发票，需审批。
- 对账单：按客户/期间生成，发送客户确认，处理差异。
- 账龄分析：0–30、31–60、61–90、90 天以上。
- 催收：逾期提醒、催收任务、承诺还款记录。
- 坏账：计提/核销需审批（可选）。

**规则：**

- 收款必须核销到具体应收/发票，未核销进入“未认领收款”。
- 开票金额不得超过应收/合同可开票金额（特殊需审批）。
- 应收调整/红冲需审批，保留原单和原因。
- 客户信用占用 = 未收应收 + 已确认未发货订单占用（口径可配置）。

### 8.3 应付、采购与费用报销

**应付来源：**

- 采购（原料、辅料、备件、办公用品）。
- 外协加工、设备维修、物流、房租、水电、服务费。
- 客户设备使用费/托管费（应付客户）。
- 员工报销、借款。

**功能：**

- 应付单、付款计划、付款申请、付款审批、付款执行、付款核销。
- 供应商发票登记、三单匹配（采购单/入库单/发票，可选）。
- 预付款、应付余额、账龄。
- 费用报销：费用类型、金额、发票、行程、客户/订单/项目归属、审批、付款。
- 借款/还款：员工借款、冲销、余额提醒。
- 费用预算：部门/项目/客户预算，超预算提醒/审批（可选）。
- 费用分摊：按部门/订单/设备/客户分摊。

**规则：**

- 付款必须关联应付/合同/发票/验收，禁止无依据付款。
- 付款审批按金额分级；大额付款双人复核。
- 出纳执行付款后回填流水号；未执行可撤回。
- 报销发票验真/查重（可选），防止重复报销。
- 应付客户设备使用费需关联设备运行记录/合同。

### 8.4 资金管理

- 银行账户、现金账户、第三方支付账户；开户行、账号、币种、余额。
- 资金流水：收款、付款、内部转账、手续费、利息。
- 银行流水导入/接口同步，自动匹配收付款，未匹配人工认领。
- 银行对账：系统余额 vs 银行余额，编制余额调节表。
- 资金计划：未来 7/30/90 天预计收款/付款，按客户/供应商/部门。
- 资金日报/月报：期初、收入、支出、期末。
- 大额/异常支付提醒；账户余额预警。
- 一期可只记录支付结果，不直连银行；银企直连作为二期。

### 8.5 成本核算

**订单成本：**

- 直接材料：领料批次成本。
- 直接人工：报工工时 × 费率。
- 设备使用费：应付客户/内部结算。
- 制造费用：水电、辅料、折旧（公司设备）、维修、外协、运费。
- 质量成本：返工、报废、赔偿。

**分摊规则：**

- 共享费用按工时、设备运行时长、产量、收入比例分摊，规则可配置。
- 按月归集，月末成本计算；在制品/成品成本分配。
- 订单毛利、客户毛利、产品毛利、设备贡献。
- 标准成本 vs 实际成本差异分析（可选）。

**库存成本：**

- 移动加权平均/先进先出/批次成本（按物料配置）。
- 客供料不计入公司存货金额，但数量参与生产耗用。
- 库存跌价/报废需审批。

### 8.6 薪酬核算（二期可选）

- 薪资结构：基本工资、岗位工资、绩效、加班费、补贴、扣款。
- 考勤数据、社保公积金、个税、请假/加班规则。
- 薪资计算 → 复核 → 审批 → 工资条 → 银行代发文件。
- 严格权限：薪资字段加密/脱敏，仅人事/财务授权人员可见。
- 与员工档案、考勤、财务费用集成。

### 8.7 对账、结账与凭证

- 客户对账、供应商对账、客户设备使用费对账。
- 月结：库存关账 → 成本计算 → 应收应付核对 → 资金对账 → 财务期间锁定。
- 结账后禁止修改历史单据；调整需反结账/红冲并审批。
- 凭证规则：业务类型 → 借方/贷方科目、辅助核算（客户/供应商/部门/订单）。
- 凭证导出/接口推送金蝶/用友；回写凭证号。
- 财务报表：应收账龄、回款、开票、资金流、费用、订单毛利、客户贡献、预算执行。

### 8.8 财务规则与权限

- 财务单据不删除；红冲/反审核需原因和审批。
- 收款/付款必须关联业务依据；无依据需特批。
- 发票、银行回单、报销单附件必须留存。
- 金额字段按角色脱敏；出纳不可修改应收应付，会计不可执行付款。
- 财务期间锁定；跨期调整需审批。
- 所有导出带水印并记录日志。
- 大额、异常、关联方交易标记，供审计。

### 8.9 验收要点

- 订单确认/发货/开票/收款形成完整应收链路，金额一致。
- 收款支持部分核销、预收、多笔合并，账龄准确。
- 付款申请、审批、执行、核销闭环，职责分离。
- 订单成本能归集材料、人工、设备使用费，毛利可追溯。
- 资金流水与银行对账可用，未匹配款项可认领。
- 月结后数据锁定，红冲/调整留痕。
- 凭证可导出/对接，科目映射可配置。

## 9. 流程审批

### 9.1 定位

统一审批中心承载全系统审批，避免每个模块重复开发。审批与业务单据解耦：流程模板可配置，业务单据提交后生成审批实例，审批结果回写业务状态。

**覆盖场景：**

- 人事：入职、转正、调岗、离职、请假、加班、补卡、出差、外勤。
- 客户：客户新建/变更、信用额度、合同、价格协议、客户合并/冻结。
- 订单：订单确认、折扣、信用超限、合同超额度、订单变更/取消、急单、超量发货。
- 设备：进场、移机、退场、维修、报废、跨客户借用、外委维修。
- 仓储：库存调整、盘点差异、报废、调拨、客供料异常。
- 财务：付款、报销、开票、红冲、坏账核销、信用解冻、预算超支。
- 权限：角色授予、临时授权、数据权限变更。

### 9.2 流程建模要素

| 要素 | 说明 |
|---|---|
| 业务类型 | 绑定表单和业务对象，如“订单折扣审批” |
| 表单 | 标准表单 + 动态字段；提交时快照，审批中不可篡改 |
| 节点 | 审批、会签、或签、依次审批、办理、抄送 |
| 审批人规则 | 指定人、角色、部门负责人、上级、岗位、发起人自选、表单字段关联 |
| 条件分支 | 金额、折扣、客户等级、部门、订单类型、设备归属异常等 |
| 审批动作 | 同意、驳回、退回发起人、转办、加签、撤回、催办 |
| 超时 | 提醒、升级、自动通过（仅低风险流程可配置） |
| 版本 | 流程模板版本化，运行中实例不受新版本影响 |

### 9.3 审批人规则

- **指定人员**：固定审批人，适用于财务/法务专岗。
- **角色**：如“财务主管”“销售总监”，按角色找人。
- **部门负责人**：发起人所在部门/客户归属部门/订单归属部门负责人。
- **上级上级**：金额超过阈值时逐级上报。
- **岗位**：如“设备主管”“仓库主管”。
- **表单字段**：如订单销售负责人、客户归属销售的上级。
- **发起人自选**：在候选范围内选择，需限制范围。
- **会签/或签**：多部门联合审批；或签任一通过即可。
- **空节点处理**：审批人不存在时跳过/转管理员/阻断，按流程配置。

### 9.4 审批操作与体验

- 我的待办、我发起的、抄送我的、已办、全部。
- 批量审批（仅限低风险、同类型）；移动端审批。
- 审批意见、附件、常用语；驳回必须填写原因。
- 转办/加签/撤回规则：已被处理不可撤回；撤回后重新提交生成新实例。
- 审批进度时间轴：谁在何时处理、耗时、意见。
- 消息通知：站内、企微/钉钉、短信/邮件；避免重复打扰。
- 审批代理：请假期间指定代理人，仅审批权限，期限可控。
- 电子签名/签章（二期）：关键合同、验收单。

### 9.5 审批场景矩阵（示例）

| 业务场景 | 发起人 | 审批链示例 | 关键校验 |
|---|---|---|---|
| 请假 | 员工 | 直属上级 → 人事 | 假期余额、排班冲突 |
| 补卡 | 员工 | 直属上级 → 人事 | 补卡次数、时间范围 |
| 订单确认 | 销售 | 销售主管 → 生产确认 → 财务（信用） | 价格、交期、信用 |
| 订单折扣 | 销售 | 销售主管 → 销售总监 → 总经理（超阈值） | 底价、毛利 |
| 信用超限 | 销售 | 财务主管 → 总经理 | 逾期、额度、回款计划 |
| 订单变更 | 销售 | 生产 → 仓储 → 财务 → 总经理（重大） | 已投产影响、成本 |
| 跨客户设备借用 | 生产 | 双方销售负责人 → 生产负责人 → 总经理 | 客户授权、设备归属 |
| 设备退场 | 设备工程师 | 设备主管 → 客户确认 → 财务（费用） | 未结工单、物资 |
| 设备维修 | 操作员/客户 | 设备主管 → 工程师 → 客户验收 | 保修、收费、备件 |
| 库存调整 | 仓管 | 仓库主管 → 财务 | 差异金额、原因 |
| 付款 | 经办 | 财务主管 → 总经理（大额）→ 出纳执行 | 合同、发票、预算 |
| 费用报销 | 员工 | 直属上级 → 财务 | 发票、标准、预算 |
| 开票 | 会计 | 财务主管 | 应收、合同、税率 |
| 权限授予 | 部门负责人 | 系统管理员 → 信息安全（可选） | 最小权限、期限 |
| 离职 | 员工/HR | 直属上级 → 人事 → 财务 → IT | 交接清单、借款 |

### 9.6 流程监控与统计

- 流程监控：运行中实例、超时、异常、被撤回。
- 审批效率：平均时长、各节点耗时、瓶颈部门、驳回率。
- 超时提醒/升级：超过 SLA 自动提醒上级。
- 审批日志不可修改；支持按单据/发起人/审批人查询。
- 流程模板变更记录；停用模板不影响历史实例。

### 9.7 验收要点

- 常见场景可通过配置完成，不需要改代码。
- 条件分支、会签/或签、转办/加签、代理、超时提醒可用。
- 审批结果正确回写业务状态；驳回/撤回能回滚业务占用。
- 移动端审批体验完整，消息触达及时。
- 审批日志完整、可审计，模板版本化。

## 10. 仓储系统

### 10.1 库存模型

**基础档案：**

- 仓库：原料仓、成品仓、客供料仓、备件仓、待检仓、不良品仓、报废仓。
- 库区/库位：支持多级库位、货架/托盘、库位容量。
- 物料：编码、名称、规格、单位、分类、批次管理、序列号管理、保质期、安全库存、默认仓库、标准成本。
- 货主：公司/客户；客供料、客户成品单独标识。
- 库存状态：可用、冻结、待检、不合格、在途、预留。

**库存维度：**

```text
仓库 + 库位 + 物料 + 批次/序列号 + 货主 + 库存状态
```

**原则：**

- 所有库存变化必须产生库存台账，禁止直接修改数量。
- 负库存默认禁止；特殊场景需审批并留痕。
- 客供料不计入公司存货金额，但数量、批次、损耗必须管理。
- 库存预留：订单确认/工单下达可预留物料，避免被其他订单占用。
- 库存成本：移动加权平均/先进先出/批次成本，按物料配置。
- 单位换算：采购单位/库存单位/生产单位可不同，换算率维护。

### 10.2 入库管理

| 入库类型 | 来源 | 关键点 |
|---|---|---|
| 采购入库 | 采购订单/送货单 | 供应商、价格、批次、质检 |
| 生产入库 | 工单/订单 | 良品/不良品、批次、质检 |
| 退货入库 | 客户退货 | 待检、原因、原订单 |
| 调拨入库 | 调拨单 | 在途、接收确认 |
| 客供料入库 | 客户 | 货主=客户、不计金额、客户签字 |
| 其他入库 | 盘盈、样品、赠品 | 原因、审批 |

**流程：**

```text
入库通知/ASN → 收货 → 质检（可选）→ 上架 → 库存台账
```

- 支持扫码收货、批次/序列号采集、保质期录入、拍照。
- 收货差异：短收、溢收、破损、错货，生成差异单并处理。
- 质检不合格进入待检/不良品仓，不参与可用库存。
- 客供料入库需客户/销售确认，记录客户物料编号、数量、批次、外观。
- 生产入库需关联工单/订单，记录良品、不良、报废数量。
- 入库单审核后库存增加；红冲需审批。

### 10.3 出库管理

| 出库类型 | 用途 | 关键点 |
|---|---|---|
| 生产领料 | 工单/BOM | 公司料计成本，客供料只记数量 |
| 销售出库 | 订单/发货单 | 信用校验、批次/序列号、物流 |
| 调拨出库 | 仓库间调拨 | 在途、接收 |
| 报废出库 | 不良/过期 | 审批、原因、照片 |
| 客供料退回 | 客户 | 货主=客户、客户签字 |
| 其他出库 | 样品、赠品、借用 | 审批、用途 |

**流程：**

```text
出库申请 → 审批（按类型/金额）→ 拣货 → 扫码复核 → 发货/领用 → 库存台账
```

- 先进先出/先到期先出建议；批次分配可手动调整。
- 生产领料按 BOM 用量，超领需审批；余料退库。
- 销售出库校验订单、信用、质检、库存；支持部分出库。
- 出库复核：物料、数量、批次、序列号、包装、标签。
- 客供料只能用于该客户订单，跨客户使用需客户授权。
- 报废需审批，财务同步做损失处理。

### 10.4 调拨、盘点与库存调整

**调拨：**

- 仓库/库位之间调拨，支持在途状态。
- 调拨申请 → 审批 → 出库 → 在途 → 接收 → 差异处理。
- 跨法人调拨（二期）需结算。

**盘点：**

- 全盘、抽盘、循环盘点；按仓库/库区/物料/批次。
- 盘点冻结库存或动态盘点（配置）。
- 生成盘点表 → 扫码/手工盘点 → 复盘 → 差异审批 → 库存调整。
- 差异原因：收发错误、损耗、丢失、计量误差、系统错误。
- 盘点报告、差异金额、责任部门。

**库存调整：**

- 盘盈/盘亏、质量降级、批次转换、货主变更。
- 必须填写原因、金额、审批；调整后更新台账。
- 库存冻结/解冻：质量、法律、客户争议时使用。

### 10.5 批次、序列号与追溯

- 批次管理：批次号、生产日期、有效期、供应商/客户、质检状态。
- 序列号管理：单件设备/产品/备件，记录入库、出库、客户、维修。
- 批次 genealogy：原料批次 → 生产批次 → 成品批次 → 发货客户。
- 客诉/召回时正向/反向追溯：从成品查原料和设备，从原料查受影响成品。
- 保质期预警：临期、过期冻结，FEFO 出库。
- 批次成本：按批次核算，支持先进先出。

### 10.6 客供料与客户库存

- 客供料入库：货主=客户，记录客户物料号、数量、批次、保质期、外观。
- 客供料库存不计入公司存货金额，但计入可用数量，供该客户订单使用。
- 客供料出库绑定客户订单/工单，损耗/报废需客户确认。
- 客户成品/半成品在库：货主=客户，单独报表。
- 客户库存对账：期初、入库、出库、结存、差异，客户签字。
- 客供料不足提醒销售/客户；客供料质量问题记录。
- 客户物资退场/退回流程。

### 10.7 订单与生产领料

- 订单确认后 BOM 展开，检查库存/在途/客供料。
- 工单下达生成领料需求，按仓库/批次预留。
- 领料单关联工单，记录公司料/客供料、批次、数量、金额。
- 超领、补料、退料、替代料均需审批/记录。
- 成品入库关联工单，更新订单已生产数量。
- 发货出库关联订单/发货单，更新已发货数量。
- 订单取消/变更时释放预留、退料、调整库存。
- 库存不足影响排产，系统提示缺料清单和预计到货。

### 10.8 库存预警与报表

**预警：**

- 低于安全库存、高于最高库存、呆滞（N 天无出库）、临期/过期。
- 负库存、库存与订单预留冲突、客供料不足。
- 盘点差异超阈值、库存金额异常波动。

**报表：**

- 库存余额表（仓库/物料/批次/货主/状态）。
- 出入库明细、库存台账、收发存汇总。
- 库存周转率、呆滞分析、ABC 分析、库龄分析。
- 安全库存预警、缺料清单、临期清单。
- 客供料库存/对账单、客户成品库存。
- 盘点差异、报废、调整明细。
- 库存金额与财务存货核对。

### 10.9 条码、PDA 与作业效率

- 物料标签、批次标签、库位标签、托盘标签、设备二维码。
- PDA/手机扫码收货、上架、拣货、复核、盘点、调拨。
- 离线作业（二期）：网络恢复后同步，冲突提示。
- 打印模板：标签、送货单、领料单、盘点表。
- 作业任务分配：收货任务、拣货任务、盘点任务，按人/组分配。
- 作业绩效：收货及时率、拣货准确率、盘点差异率。

### 10.10 关键规则与验收要点

- 库存数量只能通过单据变动，台账可追溯每笔变化。
- 客供料与公司物料严格分开，不混淆货主和金额。
- 生产领料/成品入库/销售出库与订单、工单闭环。
- 批次/序列号可追溯，临期/过期控制有效。
- 盘点差异必须审批后调整，不能直接改数。
- 库存预警、缺料提示能影响排产和采购。
- 库存金额与财务成本一致，月末可对账。

## 11. 首页大屏与管理驾驶舱

### 11.1 定位

首页不是简单的图表集合，而是 **角色化工作台 + 经营驾驶舱 + 大屏展示**：

- 员工打开系统先看到“今天要做什么”。
- 管理层看到“经营是否健康、哪里有问题”。
- 大屏用于会议室/展厅/生产现场，展示公司整体运营状态。

### 11.2 管理驾驶舱指标

**经营指标：**

- 本月/本年订单额、营收、回款、应收余额、逾期应收。
- 订单数、完成订单数、在制订单、订单完成率、准时交付率。
- 客户新增、活跃、流失、客户集中度、客户毛利贡献。
- 人均产值、订单毛利率、现金余额、资金净流入。

**生产与设备：**

- 在制工单、今日产量、计划达成率、良品率、返工率。
- 设备总数、在用/停机/维修数量、设备利用率、OEE、故障率。
- 客户设备分布、Top 客户设备产出、维保计划完成率。
- 缺料工单、延期工单、急单数量。

**仓储与财务：**

- 库存金额、库存周转率、呆滞库存、库存预警数。
- 客供料库存、客户成品库存。
- 应收账龄、逾期客户数、信用超限客户。
- 本月开票、收款、付款、费用。

**人与流程：**

- 今日出勤率、异常考勤、请假/加班人数。
- 待审批数量、超时审批、平均审批时长。
- 待办任务、预警数量。

### 11.3 角色工作台

| 角色 | 首页重点 |
|---|---|
| 总经理 | 经营指标、订单/回款、风险预警、关键审批、客户/设备概览 |
| 销售 | 我的客户、我的订单、交期预警、应收/信用、跟进提醒、待审批 |
| 销售主管 | 团队业绩、订单漏斗、折扣/信用审批、客户流失预警 |
| 生产主管 | 今日排产、设备状态、缺料、延期工单、报工异常、质量 |
| 设备工程师 | 我的设备、点检/保养待办、故障工单、证书/保修到期 |
| 财务 | 收款/付款待办、逾期应收、发票、资金余额、费用审批 |
| 仓管 | 今日出入库任务、待收货/待拣货、库存预警、盘点任务、客供料 |
| 人事 | 今日出勤、考勤异常、合同/证书到期、入离职待办 |
| 普通员工 | 打卡、我的申请、待办审批、消息、通讯录 |

### 11.4 首页大屏

**展示形式：**

- 16:9 分辨率，适配 1920×1080/4K，自动缩放，无滚动。
- 深色科技风/简洁商务风模板可选；支持轮播、定时刷新。
- 顶部：公司名称、日期时间、天气（可选）、数据更新时间。
- 中部：核心指标卡 + 趋势图 + 地图/设备分布 + 订单/生产进度。
- 底部：滚动预警、待办、设备状态、审批效率。

**推荐布局：**

```text
┌────────────────────────────────────────────────────────────┐
│ Logo  公司经营驾驶舱            2026-10-19 14:30  数据更新  │
├────────────┬────────────┬────────────┬────────────┬─────────┤
│ 本月订单额  │ 本月回款    │ 应收余额    │ 逾期应收    │ 出勤率  │
├────────────┴────────────┴────────────┴────────────┴─────────┤
│ 订单趋势（折线）        │ 订单/生产进度（漏斗/甘特）          │
├─────────────────────────┼───────────────────────────────────┤
│ 设备状态分布/客户设备地图 │ 库存预警/客户贡献/Top 客户         │
├─────────────────────────┴───────────────────────────────────┤
│ 滚动预警：延期订单｜设备故障｜信用超限｜缺料｜审批超时          │
└────────────────────────────────────────────────────────────┘
```

**大屏规则：**

- 只展示聚合数据，不展示员工身份证、薪资、银行卡等敏感信息。
- 数据权限：大屏账号按公司/部门范围配置；外部展厅使用脱敏数据。
- 刷新频率：经营指标 5–15 分钟；设备状态 30–60 秒（如接入 IoT）。
- 数据异常/断网时显示最后更新时间，不显示错误堆栈。
- 支持全屏、自动轮播、远程配置布局（管理员）。

### 11.5 KPI 口径定义（示例）

| 指标 | 口径 |
|---|---|
| 订单准时交付率 | 按期完成交付的订单行数 / 期间完成交付的订单行数 × 100% |
| 订单完成率 | 已完成订单数 / 已确认订单数 × 100% |
| 设备利用率 | 实际运行时间 / 计划可用时间 × 100% |
| OEE | 时间开动率 × 性能开动率 × 良品率 |
| 设备故障率 | 故障停机时间 / 计划运行时间 × 100% |
| 应收逾期率 | 逾期应收金额 / 应收总额 × 100% |
| 库存周转率 | 期间销货成本 / 平均库存金额 |
| 订单毛利率 | （订单收入 − 订单成本）/ 订单收入 × 100% |
| 出勤率 | 实际出勤人天 / 应出勤人天 × 100% |
| 审批及时率 | 在 SLA 内完成的审批数 / 总审批数 × 100% |
| 客户留存率 | 期间仍有成交的老客户数 / 期初客户数 × 100% |
| 人均产值 | 期间产值 / 平均在岗人数 |

**口径原则：**

- 明确统计期间、含税/未税、是否包含取消订单、按订单行还是订单头。
- 财务指标以财务确认数据为准；生产指标以报工/入库为准。
- 指标定义需在系统内维护说明，避免各部门口径不一致。

### 11.6 预警与消息

- 交期预警：预计完成晚于承诺交期。
- 设备预警：故障、停机超时、保养/点检逾期、保修到期。
- 财务预警：应收逾期、信用超限、大额付款、资金余额低。
- 库存预警：低于安全库存、临期、呆滞、客供料不足。
- 审批预警：超时未处理、流程阻塞。
- 人事预警：考勤异常、合同/证书到期、离职未交接。
- 预警可配置接收人、渠道、阈值、免打扰时间。

### 11.7 验收要点

- 不同角色登录看到不同首页，数据范围正确。
- 指标口径可配置/可说明，数字与业务报表一致。
- 大屏可全屏、自动刷新、适配常见分辨率。
- 敏感数据不出现在大屏；外部展示可脱敏。
- 预警能跳转到具体单据并处理。

## 12. 跨模块核心场景

### 12.1 新客户 + 客户设备托管 + 首单

```text
1. 销售新建客户 → 客户审核 → 分配归属/信用额度
2. 签订合同（加工服务/设备托管）
3. 设备进场：设备工程师登记客户设备、位置、配件、照片 → 客户签字验收
4. 客户客供料入库：仓储按货主=客户入库，记录批次/数量
5. 销售创建订单，选择客户设备 → 系统校验归属/信用/价格/产能
6. 订单审批 → 生成工单 → 排产到客户设备
7. 工单领料（公司料+客供料）→ 生产报工 → 质检 → 成品入库
8. 发货 → 客户签收 → 财务应收/开票 → 收款核销 → 订单关闭
9. 设备保养计划自动生成；设备运行/维保记录归入客户 360
```

### 12.2 设备故障影响订单

```text
操作员报修 → 设备主管派工 → 维修工单
 → 系统标记设备停机 → 受影响工单/订单提示交期风险
 → 生产重排（换设备/调时间）→ 通知销售/客户
 → 维修完成试机 → 设备恢复 → 工单继续
 → 维修成本/备件/客户收费进入财务
```

### 12.3 客户信用超限

```text
销售下单 → 信用校验不通过 → 阻断提交
 → 发起信用特批（回款计划/担保/总经理审批）
 → 通过后订单确认，但发货前再次校验
 → 仍超限则发货冻结，财务确认收款后释放
```

### 12.4 客供料不足/质量问题

```text
排产/领料时发现客供料不足或不合格
 → 系统提示缺料清单 → 通知销售/客户
 → 订单部分生产/延期 → 记录待料时长
 → 客供料补货入库/退换 → 质检 → 继续生产
 → 因客户原因停机可依合同计费
```

### 12.5 库存盘点差异

```text
生成盘点任务 → 冻结/动态盘点 → 扫码/手工盘点
 → 复盘 → 差异分析 → 审批 → 库存调整
 → 财务存货金额调整 → 盘点报告归档
```

### 12.6 员工离职交接

```text
离职申请 → 直属上级审批 → 交接清单
 → 客户/订单移交 → 设备责任移交 → 借款/资产归还
 → 财务结算 → IT 禁用账号/回收权限
 → 考勤封存 → 薪资结算
```

### 12.7 权限调整

```text
部门权限模板调整 → 预览受影响用户
 → 权限审批 → 生效 → 用户收到通知
 → 旧权限快照保留 → 审计可查
```

### 12.8 月末结账

```text
仓储关账（出入库截止）
 → 成本计算（材料/人工/设备/费用）
 → 应收应付核对 → 资金对账
 → 财务期间锁定 → 生成报表/凭证
 → 异常调整走反结账/红冲审批
```

## 14. 非功能性需求

### 14.1 安全与合规

- 全站 HTTPS；密码策略、登录失败锁定、MFA（管理员/财务）。
- 支持企微/钉钉扫码登录、LDAP/AD/SSO（可选）。
- 敏感字段加密存储（身份证、银行卡、薪资），页面脱敏。
- 防 SQL 注入、XSS、CSRF、越权访问；接口级权限校验。
- 文件上传类型/大小限制、病毒扫描；附件访问鉴权。
- 操作日志、登录日志、数据导出日志保留不少于 3 年（按公司制度）。
- 遵守《个人信息保护法》《数据安全法》：考勤定位/人脸需告知同意、最小化采集、权限限制、离职后按制度处理。
- 客户设备数据、客户物资数据按客户隔离，防止交叉泄露。
- 备份：每日全量 + 增量，异地/异机保留；定期恢复演练。
- 权限审计、职责分离检查、离职账号清理。

### 14.2 性能与容量

- 支持 200–500 员工、50–100 并发在线（可按实际调整）。
- 常用列表/详情页响应 < 2 秒；复杂报表 < 5 秒；大屏首屏 < 3 秒。
- 订单、库存台账、考勤记录按年增长，需支持归档/分区。
- 批量导入 1 万行以内可接受；大报表异步导出。
- 设备 IoT 数据（二期）按时间序列存储，避免影响业务库。

### 14.3 可用性与易用性

- 7×12 业务时段可用性 ≥ 99.5%；关键财务/生产时段保障。
- 断网时移动端打卡/审批可缓存重试（按场景）。
- 表单支持草稿、自动保存、必填校验、错误提示。
- 列表支持筛选、排序、列配置、导出、批量操作。
- 移动端适配手机/PDA，扫码入口明显。
- 提供操作指引、字段说明、帮助文档。

### 14.4 扩展与集成

- 模块化设计，模块间通过服务/事件解耦，便于后续扩展。
- OpenAPI/Webhook：客户、订单、库存、财务、设备状态。
- 集成：企微/钉钉（组织、消息、审批）、考勤机、电子发票、银行流水、IoT 网关、金蝶/用友。
- 自定义字段/表单/打印模板，减少二次开发。
- 多语言/多币种/多组织作为扩展预留。

### 14.5 运维与监控

- 应用日志、接口日志、慢查询日志、错误告警。
- 定时任务监控（考勤日结、库存预警、应收逾期、保养生成）。
- 数据备份/恢复、版本发布/回滚流程。
- 灰度/试点上线，先小范围验证再全公司推广。

## 15. 实施规划建议

### 15.1 优先级划分

| 优先级 | 模块/能力 | 说明 |
|---|---|---|
| P0 | 组织/员工/权限、客户主数据、设备档案、订单基础、仓储基础、审批、基础报表 | 系统骨架，必须先做 |
| P0 | 考勤基础（班次/打卡/请假/加班/补卡/月报） | 高频刚需 |
| P0 | 应收/收款/开票、费用报销基础 | 业务闭环 |
| P1 | 订单排产、工单/报工/质检、设备维保、库存批次/盘点/客供料 | 核心生产链路 |
| P1 | 应付/付款、成本核算、客户 360、经营驾驶舱 | 管理深化 |
| P2 | IoT/OEE、薪酬、客户门户、银企直连/电子发票、APS、多组织/多法人 | 后续扩展 |

### 15.2 阶段建议

**阶段 0：需求确认与原型（2–3 周）**

- 确认关键业务假设（设备位置、计价、原料归属、财务边界）。
- 输出页面原型、权限矩阵、数据字典初稿、审批场景清单。
- 选定试点部门/客户/设备/仓库。

**阶段 1：基础平台 + 核心主数据（4–6 周）**

- 组织/员工/权限、客户、设备档案、物料/仓库、编码/字典/附件/日志。
- 员工考勤基础、审批引擎基础。
- 基础报表与导入导出。

**阶段 2：订单—生产—仓储—应收闭环（6–8 周）**

- 订单、工单、排产、报工、质检、成品入库、发货。
- 领料/客供料/库存台账/盘点。
- 应收/收款/开票；设备维保基础。
- 首页工作台 V1。

**阶段 3：财务深化 + 设备 + 驾驶舱（4–6 周）**

- 应付/付款/费用/资金/成本。
- 设备点检/保养/维修/运行。
- 客户 360、经营驾驶舱、大屏。
- 权限复核、审计报表。

**阶段 4：扩展与优化（持续）**

- IoT、薪酬、客户门户、银企直连、电子发票、APS、多组织。
- 根据使用数据优化流程和指标。

> 以上为建议节奏，实际取决于团队规模、业务复杂度和数据准备情况。

### 15.3 数据迁移与上线

- 迁移范围：客户、联系人、合同、设备、物料、期初库存、未结订单、应收应付、员工/考勤基础数据。
- 提供标准模板、校验规则、试导入、差异报告。
- 期初库存/应收应付需财务确认，形成迁移基准。
- 试点：选 1–2 个部门/客户/仓库并行运行 2–4 周，核对数据。
- 培训：分角色培训（销售、生产、设备、仓储、财务、人事、管理员），提供 SOP 和视频。
- 上线切换：冻结旧数据 → 迁移 → 核对 → 切换 → 支持期驻场。
- 建立超级用户/关键用户机制，负责一线答疑和需求收集。

### 15.4 主要风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| 客户设备权责不清 | 设备/费用/责任纠纷 | 进场验收、托管协议、客户签字、费用规则前置确认 |
| 订单计价/原料归属复杂 | 成本与应收算不准 | 先梳理计价模型和 BOM/客供料规则，试点验证 |
| 权限配置过细 | 维护成本高、易出错 | 部门模板 + 角色 + 少量用户例外；定期复核 |
| 基础数据质量差 | 报表不准、流程卡住 | 主数据责任人、导入校验、期初核对 |
| 财务对接复杂 | 重复录入/对账困难 | 明确边界，先业务财务，后总账接口；科目映射先行 |
| 用户抵触 | 上线失败 | 试点、培训、简化操作、移动端优先、关键用户参与 |
| 需求蔓延 | 延期/超预算 | 阶段范围冻结，变更评审，P0/P1/P2 分级 |
| 考勤合规 | 劳动纠纷/隐私风险 | 制度公示、员工同意、数据最小化、异常申诉 |

## 16. 待确认问题清单

以下问题直接影响数据模型和流程设计，建议在开发前逐项确认：

### 业务模式

1. 客户设备主要放在哪里？公司场地托管、客户现场驻场，还是两者都有？比例如何？
2. 设备由谁操作？公司员工、客户员工，还是共同操作？
3. 订单计价方式是加工费、产品销售、设备使用费，还是组合计价？
4. 原材料由谁提供？公司采购、客户提供、部分客供？客供料损耗如何结算？
5. 公司使用客户设备是否需要向客户支付设备使用费/托管费？如何计算（时长/产量/固定月费）？
6. 客户设备维修/保养由谁负责？是否收费？保修责任如何划分？
7. 是否存在跨客户借用设备？审批层级和授权文件要求？

### 组织与权限

8. 公司是否有多个法人/工厂/仓库？一期是否需要多组织？
9. 部门权限是否需要“父部门锁定、子部门不可扩大”？
10. 哪些字段属于敏感字段（金额、成本、毛利、折扣、客户联系方式、员工薪资）？
11. 权限变更是否需要审批？由谁审批？是否需要季度复核？
12. 是否需要客户/供应商外部账号？

### 财务

13. 目前使用什么财务软件（金蝶/用友/其他）？是否需要凭证对接？
14. 是否需要总账、税务申报、薪资核算、银企直连、电子发票？
15. 应收/信用口径：信用额度是否包含未发货订单？逾期如何计算？
16. 成本核算希望做到订单级、工单级还是产品级？分摊规则是什么？
17. 是否有外币、多税率、多结算方式？

### 考勤与人事

18. 考勤硬件品牌/型号？是否支持接口？是否使用人脸识别？
19. 班次类型（固定/排班/综合工时）、加班规则、请假额度规则？
20. 是否需要薪资核算？考勤结果如何对接薪资？
21. 员工定位/人脸采集的合规告知和同意流程是否已具备？

### 订单与生产

22. 订单变更/取消/超量发货的审批规则？
23. 质检标准、不良代码、返工/报废流程？
24. 是否需要工序级管理（多工序流转）还是工单级即可？
25. 排产希望做到什么程度？手工拖拽、自动建议、有限产能？
26. 客户是否要查看订单/生产/设备进度？

### 仓储

27. 仓库数量、类型、是否多库位？是否需要批次/序列号/保质期管理？
28. 是否存在客供料、客户成品、寄售、借料等特殊库存？
29. 是否需要 PDA/条码/RFID？现有硬件情况？
30. 库存成本方法（移动加权平均/先进先出/批次）？

### 实施

31. 预计用户数、并发数、部署方式（私有化/云）、预算和上线时间？
32. 现有系统（ERP/CRM/财务/考勤）有哪些？需要迁移哪些数据？
33. 一期试点部门和成功标准是什么？

## 17. 下一步工作建议

1. **业务访谈**：按销售、生产、设备、仓储、财务、人事、管理层分别访谈，确认第 16 节问题。
2. **流程走查**：选 2–3 个真实客户/订单/设备，从下单到回款完整走一遍，画出实际流程和单据。
3. **原型设计**：优先做客户 360、订单详情、排产看板、设备档案、库存台账、权限配置、审批中心、首页大屏。
4. **权限矩阵确认**：用真实部门/岗位填一版权限矩阵，验证“部门模板 + 角色 + 用户例外”是否够用。
5. **数据字典**：确定核心表、字段、状态、编码规则、必填校验。
6. **接口清单**：确认企微/钉钉、考勤机、财务软件、发票、银行、IoT 的接口方式和责任方。
7. **试点计划**：选试点部门/仓库/客户，定义上线验收指标（如订单准时率、库存准确率、考勤差错率、审批时长）。
8. **排期与预算**：按 P0/P1/P2 拆分迭代，明确一期范围、里程碑和验收标准。
