## 1. 说明

- 全部页面为 **PC Web 后台 + 业务页面**，浏览器访问；不做小程序、App、PDA。
- 页面按优先级标注：**P0 上线必备、P1 管理深化、P2 后续扩展**。
- 权限采用“角色 + 数据范围 + 字段权限 + 操作权限”四层控制；本文件为矩阵设计基线。
- 具体交互与视觉稿在原型阶段细化；页面编码（如 `ORDER-01`）用于开发排期与测试用例编号。

## 4. 关键页面原型说明

### 4.1 HOME-01 角色工作台

- **目标**：登录后 3 秒看到“今天要干什么”。
- **区块**：
  - 顶部：待办数量（审批、确认、预警）、快捷入口（按角色）。
  - 指标卡：按角色不同（业务员：本月成交/回款/逾期；生产：在制/延期/设备在线率；财务：应收/应付/超限客户；设备管理员：离线设备/OCR 待确认/故障）。
  - 列表：待办明细（可点击直达）、交期预警、信用预警、设备告警。
- **规则**：数据范围随角色（工厂/部门/本人客户）；卡片可配置。

### 4.2 HOME-02 大屏

- **目标**：展厅/管理层全屏展示。
- **区块**：今日订单与产量、在制订单进度、设备在线率与队列、各工厂产出对比、质量/返工率、应收与回款、异常滚动条。
- **规则**：6–8 个组件轮播或一屏；数据 60 秒刷新（可配置）；只读。

### 4.3 CUS-03 客户 360

- **布局**：左侧客户信息卡（来源、归属业务员、结算方式、信用额度/已用/可用、标签），右侧 Tab。
- **Tab**：图案库、报价、合同、订单、发货、应收/回款、发票、跟进记录、变更历史。
- **关键操作**：新建报价/订单、登记跟进、发起收款认领、申请提额、移交客户（走审批）。
- **规则**：业务员仅见本人客户（或授权范围）；财务可见结算与信用字段；成本/毛利字段按字段权限显示。

### 4.4 QUO-02 报价编辑

- **布局**：表头（客户、图案、有效期、结算方式）+ 明细行表格。
- **明细行字段**：材料、染料、工艺、门幅（米）、长度（米，2 位小数）、单价（元/米，4 位小数）、金额（分、截取）、备注。
- **校验**：必填材料/染料/工艺/长度；长度 2 位小数、单价 4 位小数；金额=单价×长度后按分直接截取，不允许手工改总额（可改单价/长度联动）。
- **操作**：保存草稿、提交审批（按金额档位）、转订单、打印/导出。
- **规则**：报价有效期到期自动失效；历史报价留版本。

### 4.5 CON-02 合同录入（财务）

- **布局**：合同基本信息（编号、客户、期限、结算方式、金额、附件）+ 关联订单/报价列表 + 状态流转。
- **操作**：录入保存（状态：待财务录入 → 已录入 → 生效）、上传扫描件、关联订单、变更版本。
- **规则**：合同由销售与客户线下确定，系统内由财务正式录入；**所有订单必须关联已录入合同，未关联不允许提交**；合同执行额度与订单/回款联动统计。

### 4.6 ORD-02 新建订单

- **布局**：步骤式或单页分区 — 客户与图案 → 明细行（材料/染料/工艺/门幅/长度/单价/金额）→ 生产工厂（单选）→ 交期与备注 → 合同与信用校验 → 提交。
- **规则**：
  - 生产工厂只有 1 个，保存后不可跨厂；后续拆单仅限同厂不同设备。
  - 金额按分截取；材料成本不在此录入（来自采购入库）。
  - 提交时校验：信用额度（未收应收 + 已确认未发货占用，逾期超 30 天阻断）、已录入合同（必选）、报价有效性。
  - 提交后生成待排产工单，进入所选工厂设备队列。

### 4.7 ORD-03 订单详情

- **布局**：顶部状态条（含排队中/生产中/已完成）+ 标签页。
- **Tab**：明细与金额、生产与设备（工单、设备分配、队列号、预计时间）、发货、应收与回款、开票、变更历史、附件。
- **设备联动**：显示设备上报的进度（米/%）、耗墨量、预估剩余时间、最后上报时间；离线/超期高亮。
- **操作**：变更申请、急单插队申请、返工确认、催办、导出。

### 4.8 PRD-01 排产工作台（设备队列）

- **布局**：左侧设备列表（工厂/车间/状态），右侧每台设备的队列泳道：当前任务卡 + 排队任务卡（队列号、订单、长度、预计开始/完成、是否插队）。
- **操作**：分配/调整设备、拆分工单到同厂不同设备、调整队列、插队审批入口（无冻结窗口）。
- **规则**：一台设备同一时间只处理一个订单；超出按 FIFO 排队；插队需销售申请+厂长审批，无补偿；队列时间按设备能力与剩余长度估算。

### 4.9 EQ-07 设备实时看板

- **布局**：设备卡片墙（在线状态、当前订单、进度条、耗墨量、速度、预估剩余、最后上报时间）。
- **操作**：点击进设备详情；离线/故障卡片置顶；支持按工厂/车间筛选。
- **规则**：数据来自 order/status 上报；离线判定按配置（默认 3 个周期）；上报超期标黄，离线标红。

### 4.10 EQ-08 OCR 待确认

- **布局**：左图片预览（缩放、旋转），右侧识别结果（OCR 文本、置信度、设备、上报时间）+ 候选订单列表（按相似度）+ 处理动作。
- **操作**：匹配到订单、标记无需处理（选原因）、重新识别、查看原图。
- **规则**：仅显示 `match_status = failed/pending` 的图片；处理需权限 `iot:ocr:handle`；处理后归位暂存的订单作业数据并记录处理人。

### 4.11 WH-02 入库单（采购入库）

- **布局**：表头（供应商、工厂/仓库、采购订单、到货日期）+ 明细行（物料、批次/卷号、数量、单价、金额、入库成本）。
- **规则**：材料成本在此录入并入库；这是材料成本的唯一来源；批次/卷管理；到货差异登记；入库后更新库存与应付。
- **操作**：保存、提交审核（可按金额档位）、打印入库单、关联质检。

### 4.12 WH-04 跨厂调拨

- **布局**：调出仓库 → 调入仓库、明细、在途状态、接收确认、差异处理。
- **规则**：跨厂调货需审批（按配置档位）；调拨不改变物料成本口径；在途库存可查。

### 4.13 FIN-01 信用额度

- **布局**：客户额度列表（额度、已用、可用、逾期、状态）+ 调整记录 + 超限客户预警。
- **操作**：申请提额/降额（审批）、临时解控（审批+期限）、导出。
- **规则**：已用额度 = 未收应收 + 已确认未发货订单占用（固定口径）；应收逾期超过 30 天或超限阻断下单/发货；全部调整留痕。

### 4.14 FIN-03 收款登记与核销

- **布局**：收款单（客户、金额、方式、账户、凭证）+ 待核销应收列表 + 核销明细（支持部分/多笔/预收）。
- **规则**：金额按分；核销后更新应收余额、账龄；可反核销（需权限+审批）；待认领款项单独列表。

### 4.15 FIN-08 费用报销

- **布局**：报销单（类型、明细、金额、附件、归属职能部门/工厂）+ 审批流 + 付款状态。
- **规则**：报销范围固定为差旅、业务招待、采购、其他；借款/还款独立单据；审批按金额档位；付款后转应付结清；可归集到工厂/职能部门/订单。

### 4.16 FIN-10 订单成本/毛利

- **布局**：订单维度表（收入、直接材料成本（来自采购入库领用）、返工损失、毛利、毛利率）。
- **规则**：本期不做成本分摊（人工/能耗等）——页面需标注“直接成本口径”；费用分摊规则为后续扩展；导出需权限并记录日志。

### 4.17 FIN-11 审批金额档位设置

- **布局**：业务类型（采购、报销、合同、提额、订单变更等）× 金额区间 × 终审层级 × 生效时间。
- **操作**：新增/复制/停用档位；调整需审批并留版本（历史单据按提交时档位执行）。
- **规则**：由财务手动维护；**系统不预置初始档位**；金额以分比较；档位为空时禁止提交并提示。

### 4.18 APR-01 审批中心

- **布局**：Tab（待我审批、我发起的、已办、抄送）+ 列表 + 详情（单据摘要、审批链、历史意见、附件）。
- **操作**：同意/驳回/转办/加签/催办/撤回（首节点前）。
- **规则**：按提交时组织快照逐层审批；发起人自己的节点自动跳过；审批人空缺按配置（跳过/转上级/阻塞）；金额档位决定终审层级；全程留痕。

### 4.19 SYS-04 角色权限

- **布局**：左角色列表，右 Tab（功能权限树、数据范围、字段权限、成员）。
- **操作**：新建/复制角色、勾选权限点、设置数据范围、设置字段可见/可编辑、分配成员。
- **规则**：工厂隔离为数据范围的一种；权限变更需二次确认并记录审计；预置角色不可删除（可复制）；导出/成本/毛利等敏感权限单独控制。

## 6. 原型交付建议

1. **原型工具**：Figma / Axure / 墨刀任选；输出可点击原型 + 页面标注。
2. **每个页面包含**：正常态、空态、加载态、错误态、无权限态、审批中/已生效态。
3. **必须评审的高风险页面**：ORD-02 新建订单、ORD-03 订单详情、PRD-01 排产工作台、EQ-08 OCR 待确认、WH-02 采购入库、FIN-01 信用、APR-01 审批、SYS-04 角色权限。
4. **打印/导出页面**：订单、发货单、入库单/出库单、调拨单、对账单、报销单、报表（统一模板与编码）。
5. **状态机图**：订单、工单、设备队列、合同、应收、报销、审批单据各一张，随原型一并评审。
6. **字段说明表**：每页附字段名、类型、必填、来源、权限、校验规则，供开发与测试直接使用。
7. **评审顺序**：业务规则确认 → 原型走查（2–3 个真实场景）→ 权限矩阵确认 → 字段与状态机冻结 → 进入开发。
